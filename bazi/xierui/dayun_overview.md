人生被分成 **八个十年大运**，每一步有独特的能量配置。这份文档逐一解释每一步。

### 0.2 十神：每十年的"主角是谁"

"十神"是十种**能量角色**，描述外来能量与你的关系。下表给出生活化对照：

| 十神 | 与你的关系 | 对应的现实角色 / 能量 |
|------|-----------|----------------------|
| **比肩** | 与我同性同气 | 同辈、合伙人、自我能量、行动力 |
| **劫财** | 与我同气但异性 | 兄弟姐妹、竞争者、消耗型同伴、冲动消费 |
| **食神** | 我所生且温和 | 温和的创作、艺术、孩子、表达 |
| **伤官** | 我所生但激烈 | 批判性思考、独立创作、不守规则、灵感 |
| **偏财** | 我克者但流动 | 副业、机会型收入、流动资源 |
| **正财** | 我克者且稳定 | 正式工资、固定资产 |
| **七杀** | 克我但强烈 | 巨大压力、目标驱动、考验、**女命的伴侣（对峙型）** |
| **正官** | 克我但温和 | 规则、正式职位、**女命的伴侣（温和型）**、社会身份 |
| **偏印** | 生我但偏门 | 非主流学问、玄学/灵性、独特天赋 |
| **正印** | 生我者 | 母亲、师长、学历、精神滋养、保护 |

> 简化记忆：**"印"是滋养你的，"比劫"是和你一伙的，"食伤"是你输出的，"财"是你赚的，"官杀"是压你的**。

### 0.3 五行对谢睿的具体含义

谢睿是丙火日主，所以五行对她来说意义如下：

| 五行 | 在十神里是什么 | 对她意味着 |
|------|---------------|-----------|
| **木** | 印星（生我） | ★ 学习 / 师长 / 精神支撑 / 读书思考的能量 —— **命局最缺，是第一关键** |
| **火** | 比劫（同我） | 自己的能量、行动力、表达欲 |
| **土** | 食伤（我生） | 输出、创作、表达成果 |
| **金** | 财星（我克） | 现实资源、工作回报、钱 —— 命局已盛，**再加就过** |
| **水** | 官杀（克我） | 外部压力、规则、伴侣议题 —— **再加压力就大** |

### 0.4 "合冲刑害"：每十年大运怎么和原局互动

每一步大运的天干地支会和你原局发生互动，剧烈程度从轻到重：

| 互动 | 通俗解释 | 体感 |
|------|---------|------|
| **合** | 两个能量被拉到一起、绑定 | 关系/局面被联动，可能转化方向 |
| **半合 / 三合** | 多个地支合成一个完整能量 | 大格局形成（三合最强） |
| **冲** | 两个能量直接对抗 | **剧烈变动、被迫面对、突变** |
| **刑** | 持续的摩擦、损耗 | 暗伤、慢性问题、关系不和 |
| **害** | 暗中损害 | 不易察觉的损耗、关系阴影 |
| **伏吟** | 同字重叠（运的字 = 原局的字） | 旧模式重演、能量复刻 |

### 0.5 用神 / 喜神 / 忌神

- **用神 = 命局最缺、最需要补的能量** → 谢睿的用神是 **木**（学习 / 精神滋养类）
- **喜神 = 用神之外有助益的能量** → 谢睿的喜神是 **火**（自我能量）
- **忌神 = 命局已经过盛、再加就坏的能量** → 谢睿的忌神是 **金水**（现实资源 + 外部压力）

### 0.6 一句话理解谢睿的命局

> 她是一个"**内核坚硬但根基偏虚**"的人。
>
> 现实压力（金水）从外面包围，自我能量（火）有但不够充足，最缺的是"精神滋养"（木 = 学习 / 师长 / 内在体系）。
>
> **她一生的大运任务，就是逐步把"缺的木"补回来，让"火"能持续燃烧。**

读到这里就可以继续往下了。下面会逐步看每一个十年发生什么。

## 三、八步大运逐运详解

### ◇ 第一步 · 戊申（2005-2014，4-13 岁）

> **童年定型期 · 财杀延续 · 食神显化**

#### 干支结构
- **天干戊**：食神（原局无戊透干，此运首透）
- **地支申**：与原局时支申完全相同 → **申申伏吟**（含庚偏财、壬七杀、戊食神）
- **旺衰**：病（丙火在申为病地）

#### 与原局的核心互动
| 互动类型 | 内容 | 权重 |
|---------|------|------|
| 申申伏吟 | 时柱气场被强化复刻，财杀根加重 | 中 |
| **金气连片加深** | 月酉 + 时申 + 运申 → 金气盘踞，财星之势更纯 | **高（结构性增忌）** |
| 杀根加深 | 申中壬为年干壬七杀之根，运支再现 → 杀根更稳 | 高 |
| 食神透干 | 戊食神首透，但坐申被泄、力薄 | 中 |

#### 整体性质：**忌方向偏重**
- 金气加深 + 杀根加深 → 财生杀的消耗链条更深
- 戊食神虽透但坐申被泄，缓和力有限
- 童年身体格局未稳逢金水重运，多见身体偏弱、易感冒、肠胃食欲等小恙之相

#### 这十年的核心课题
> **环境定型期。** 家庭、学校等外部"现实结构"对本造的塑造在此期被强化；命主"对外结构感强、对内退守感强"两极特质的早期奠基。

#### 前五年 vs 后五年
- **2005-2009（戊主导）**：食神主表达，幼年期看似温和但戊坐申泄不显其用
- **2010-2014（申主导）**：申申伏吟力量成型，金水气场彻底定盘

#### 一句话总诀
> 童年定型期。被外部结构塑造的十年。

#### 白话版（这十年到底什么意思）

**对应人生阶段：上幼儿园到小学毕业。**

- **命运给的卡片**：被环境塑造
- **现实表现**：
  - 跟着父母、学校、老师走，外部规矩在你身上定型
  - 这个阶段你没有太多主动选择权，主要是被环境塑造
- **身体方面**：童年金水气场重，可能体质偏弱、容易感冒、肠胃食欲不规律
- **心理底色**：开始形成"对外界规则敏感、对内退守"的性格基础
- **后果**：这十年的家庭/学校经历，很大程度上塑造了你后来面对压力的方式

> 对成年的你来说，这一步只是 **"理解你为什么是现在这样"** 的背景资料。重点不在这。

### ◇ 第二步 · 丁未（2015-2024，14-23 岁）

> **学业奋斗期 · 火气首补 · 库刑动**

#### 干支结构
- **天干丁**：劫财（与日干丙同气，火气直接补强）
- **地支未**：含己（伤官本气）+ 乙（正印中气）+ 丁（劫财余气）→ **一支三象，含原局最缺之木印**
- **旺衰**：衰

#### 与原局的核心互动
| 互动类型 | 内容 | 权重 |
|---------|------|------|
| **午未六合** | 启动午之空亡（合中带动）—— 帝旺根以"被合方式"被引而出 | **高** |
| **戌未相刑** | 戌火库被"刑动"，藏干丁辛戊出动一线 | **高** |
| **丁火透干扶身** | 第一次外部补火 | **高（用神到位）** |
| 乙木藏未（印星萌芽） | 原局无木，未中乙首次出现地支藏干，但未透干、被己土夺气 | 低（仅作铺垫） |

#### 整体性质：**扶抑大体偏吉，但带"刑合并发"之动**
- 丁火劫财 + 午未合启动午根 → 火气补强是结构性受益
- 戌未刑同步发生 → 内核根据地（戌）被刑动，伴随"内在不安定"感
- 未中乙木藏而未透 → 印星之利未能真正落地，仅为后续乙巳运埋伏笔
- **净评**：扶身有效，但启动方式偏"刑动"而非"合温" → 学业奋斗期的张力与起伏并存

#### 这十年的核心课题
> 以学业为外象的奋斗期。火气补强使主观能动性显化，但"戌未刑"与"午未合"同时发生 → 内在根基处于"被搅动"状态。命主体感常为"**外在拼搏 + 内在浮动**"。

#### 前五年 vs 后五年
- **2015-2019（丁主导）**：劫财扶身正面，初中至高一阶段火气补给最直接
- **2020-2024（未主导）**：刑合主导，高考-本科期间外部刺激与内在动荡并发；2024 甲辰流年已开始为下一步丙午做交接铺垫

#### 一句话总诀
> 学业奋斗期。火气首至，外强内紧，为青年期蓄势。

#### 白话版（这十年到底什么意思）

**对应人生阶段：初中到大学毕业。**

- **命运给的卡片**：火气第一次进来扶你 + 老问题翻动
- **现实表现**：
  - 第一次有"为自己拼"的能量（丁火劫财扶身）
  - 但内心常有"不安定"感（戌未刑、午未合搅动旧能量）
  - 学业是这十年的主线 —— 高考、本科、初入社会
- **关键体感**：
  - 外面看：努力、能拼、有目标
  - 里面感：常觉得"根不稳"、情绪起伏大
- **后果**：这十年是"**外强内紧**"人格底色形成的关键期。你身上"硬撑+敏感"的两面性，很多源自这十年。

> 这一步对当下的你（24 岁）来说，是 **"刚结束的过去"**。下一步丙午才是当前。

### ◇ 第三步 · 丙午（2025-2034，24-33 岁）★ **当前进行**

> **扶身先行 · 比劫齐至 · 午填空 · 火主线复位**

#### 干支结构
- **天干丙**：比肩（与日干同气，自气直接外延）
- **地支午**：含丁（劫财本气）+ 己（伤官中气）→ **比劫为主、伤官次之；填实年支午空亡**
- **旺衰**：帝旺

#### 与原局的核心互动
| 互动类型 | 内容 | 权重 |
|---------|------|------|
| **★ 填实空亡** | 运支午 = 年支午 → 直接填实日空之午，**帝旺根由虚转实** | **极高（结构性转折）** |
| 午戌半合升级 | 火气盘面由"半实半虚"转为"实链" | 高 |
| **天干双丙变三丙** | 比肩之势在天干极强 | 高 |
| 子午冲预警 | 当流年子来冲时，由"空冲"转"实冲"，冲力强化 | 高（流年触发风险） |
| **★ 无木为源** | 比劫齐至但运中无木 → 火气虽强却"**孤旺无源**" | **高（结构性隐患）** |

#### 整体性质：**结构性最大补强期，但带"孤旺无源"之隐患**
- **扶身力量为命中最强**：午填空 + 双丙变三丙 + 午戌半合稳固 → 日主从"偏弱有根"走向"有底有面"
- **但木印缺席** → 火气无源持续 → 易过燃、易精神透支
- 表象：自我主张、行动力、表达欲在此期最强；但若用而不节，会出现"强光透支"式疲惫

#### 这十年的核心课题
> 本造从"静态偏弱"走向"动态可用"的最早窗口，也是命主真正可以"以自身之力博弈现实"的开端。
>
> **课题不在锋芒能否出来，而在于：火过燃时如何节制、温养，避免在没有木印通道的情况下消耗过深。**

#### 前五年 vs 后五年
- **2025-2029（丙主导）**：比肩透干 + 午根复位双重作用，火气最盛 → 主观能动性、社会能见度抬升最快
- **2030-2034（午主导）**：午填空之效持续；流年若见子（如 2032 壬子）则触发实冲，属预警节点

#### 一句话总诀
> 扶身先行期。力量大但缺源，可博弈而易透支。

> 详细流年级展开见 `dayun_bingwu_liunian.md`

#### 白话版（这十年到底什么意思）★ **当前进行中**

**对应人生阶段：现在（2025）到 33 岁（2034）。**

- **命运给的卡片**：行动力爆棚 + 但精神燃料没补
- **现实表现**：
  - 自我意识空前强、想主导、敢拼、表达欲旺
  - 外部能见度抬升 —— 容易被看见、容易出头
  - 但**容易透支** —— 你能开多猛的车，取决于油箱里有多少"印"（学习 / 精神支撑）

### 9.3 重点大运的"为什么这样调"

不是每一步都需要详细解释，重点说明几个有"反常识"侧重的大运。

#### 丙午运（2025-2034）★ 当前

> **疑问**：9 看似双重吉数（喜神火 + 当令离火），为什么要降级？

**因为命主原局是"火根虚浮 + 木源缺"。** 丙午运下，**外部的火气已从大运满给**（双丙透干 + 午填实空亡 + 午戌半合升级）—— 自身的火气已经过旺。此时再用 9 数字大量叠加，等于"火上加火"，等于让本就紧绷的命局更绷一分。

**核心原则**：丙午运第一推荐 **3、4**（补木为源 + 木生火转化为可用之火）。9 不变忌神，但**降级使用** —— 手机号末位避免 9，但中段含 9 不必刻意避。

#### 乙巳运（2035-2044）

> **疑问**：为什么 9 又能用了？

**因为乙巳运的火气是"禄位"性质**（巳为丙火禄位）—— 是稳定的、有印星统御的火，不是"过燃"的火。同时乙木正印首透 → 火有了源头，多用 9 反而能让"印 → 比劫 → 用"的链条流通起来。

**核心原则**：乙巳运 **3、4、9 全用**，是一生中助运最完整的窗口之一。

#### 甲辰运（2045-2054）

> **疑问**：为什么 1（水）从"基线避"升级为"严避"？

**因为辰本身藏癸水，且与时支申半合带水气**，本运水气加重。如果再用 1 数字加水气，会触发"水多压火"，让原本就被冲开的戌火库雪上加霜。

**核心原则**：甲辰运不仅避 6、7 金，**1 水也要严格避**。

#### 辛丑运（2075-2084）

> **疑问**：为什么 9 又要降级了？

**因为辛丑运中"丑戌相刑"** → 戌火库被刑动 → 戌中藏丁火被散。同时金气再聚（巳酉丑半合金）。这时火气是"**被散**"的状态，不是"被增"。9 数字虽属火，但承接不住散气。

**核心原则**：辛丑运退回到"**补木保火**"，3、4 第一推荐，9 降级使用。

### 9.4 助运的边界提醒

数字、颜色、饰品、饮食这些后天调整都是**辅助手段**，能量量级低于：

1. 命局本身（先天）
2. 行运（大运 / 流年）
3. 风水居所（居住空间气场）
4. 心性 / 行为（主观选择）

> **不要把数字 / 颜色 / 饰品当成"换运法宝"**。它们只是在已确定的命局 + 行运框架下，让能量稍稍偏向有利方向 —— **是锦上添花，不是雪中送炭**。

不同流派的对比、为什么本章不采用"数字能量学"等深度内容，参见 [`reference/shuzi_zhuyun.md`](../../reference/shuzi_zhuyun.md)。
