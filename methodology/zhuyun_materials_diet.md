## 三、材质 / 饰品助运

### 3.1 核心机制

材质对人的能量影响通过**贴身长期接触**累积，主要通路：

1. **物质五行属性**：金属属金、玉石属土、木质属木、水晶属水（部分）、陶瓷属土等
2. **形状五行属性**（次要）：方形属土、圆形属金、长形属木、波纹属水、尖形属火
3. **颜色五行属性**：参 [`yanse_zhuyun.md`](./yanse_zhuyun.md)；与材质共同决定整体五行倾向

> **铁律**：**先有用神判定，再选材质**。"招财水晶"、"辟邪玉佩"等通用商品话术不属于本方法论。

### 3.2 五行 ↔ 材质映射

| 五行 | 主要材质 | 典型代表 |
|---|---|---|
| **木** | 木材、植物纤维、有机棉麻、纸 | 紫檀 / 橄榄木 / 沉香 / 檀香 / 木佛珠 |
| **火** | 皮革、皮草、丝绸、塑料（带光泽）、陶瓷（带釉） | 皮带 / 皮包 / 真丝 / 釉面陶瓷 |
| **土** | 玉石、陶土、石材、瓷器、黏土 | 玉佩 / 翡翠 / 玛瑙 / 砂岩 / 陶器 |
| **金** | 金属、合金、矿石（金属类） | 金 / 银 / 铜 / 铁 / 钢 / 不锈钢饰品 |
| **水** | 水晶、玻璃、贝壳、珍珠、流体材质 | 水晶 / 玻璃饰品 / 珍珠 / 贝壳饰品 |

> **注意**：水晶在传统命理中归**水**（透明流动 + 反射光），不归土。但部分商业话术按矿物学将水晶归矿石（土），这是错位。本文采纳传统命理归类。

详细映射 + 形状 + 颜色组合见 [`lookup_tables.md`](./lookup_tables.md) §十八。

### 3.3 三层框架的应用

#### 第一层 · 命主用神

例：丙火日主，喜木火，忌金水。

#### 第二层 · 五行 → 材质

| 用神 | 推荐材质 | 避免材质 |
|---|---|---|
| 木火 | 木质（紫檀 / 沉香）+ 皮革 / 丝绸 + 釉面陶瓷 | 大量金属 + 水晶 / 玻璃 / 珍珠 |
| 土火 | 玉石（黄玉 / 黄翡）+ 陶瓷 + 皮革 | 木质大件（木克土）+ 水晶 |
| 金水 | 金属（金 / 银）+ 水晶 / 玻璃 | 大量木质 + 釉面陶瓷 |

#### 第三层 · 时空加权

2024-2043 九紫离火运下：
- 火属材质（皮革 / 丝绸 / 釉面瓷）→ 时代加分
- 木属材质（紫檀 / 沉香）→ 木生火加分
- 土属材质（玉石 / 陶瓷）→ 退气小幅加分
- 金属（金 / 银 / 铜）→ 时代退气，单独大件慎用
- 水晶 / 玻璃 → 时代衰气

### 3.4 应用场景的能量量级

| 等级 | 场景 | 重点判断 |
|---|---|---|
| ★★★★★ | **贴身佩戴**：项链 / 手串 / 戒指 / 耳饰 / 手表 | 必须用神材质；24/7 接触强度最大 |
| ★★★★ | **常用随身**：钱包 / 钥匙扣 / 手机壳材质 / 包扣件 | 主用神材质；点缀可加 |
| ★★★ | **居所主件**：玄关摆件 / 客厅主装饰 / 床头柜上物品 | 主用神材质，但配合居所整体 |
| ★★ | **办公位**：桌面摆件 / 鼠标垫 / 笔筒材质 | 偶尔触及，影响中等 |
| ★ | **偶发饰品**：节日礼物 / 偶尔佩戴的饰品 | 影响有限，不严格按用神 |

### 3.5 命局矛盾时的材质取舍

#### 喜火 + 火过盛
- **不要全身堆皮革 / 釉面瓷** → 火气过载
- 改用木质（紫檀 / 沉香）→ 木生火但本身偏温润，不至于催发
- 或玉石（中性偏土）→ 火生土，泄火气

#### 喜水 + 水过弱
- 大胆补水：水晶 / 珍珠 / 玻璃饰品
- 配合金属（金生水）作辅
- 避免大件木质（水生木 = 泄水）

#### 喜金但金过燥（如夏季出生 + 燥金多）
- 不要堆纯金属（金过旺反伤）
- 改用水晶 / 玻璃（金生水，泄燥金）+ 少量金属点缀

### 3.6 饰品的整合判断（材质 + 颜色 + 形状）

饰品是材质 + 颜色 + 形状三维叠加。判断流程：

1. **主轴**：材质五行（如玉佩 = 土）
2. **辅轴**：颜色五行（如绿翡 = 木）
3. **微调**：形状五行（如圆形 = 金，长条 = 木）

**示例**：一块**绿色玉佩长条形** = 土（玉）+ 木（绿）+ 木（长条）→ 整体偏木气，对喜木命主有加成；但土材质本身仍是底色，不会变成"纯木"。

### 3.7 常见误区

| 误区 | 纠正 |
|---|---|
| "玉佩对所有人都好" | 玉属土，对喜土 / 喜火（火生土）命主好；对喜木命主（木克土）反而不利 |
| "金器招财" | 金器属金，对喜金命主有用；对喜木命主（金克木）适得其反；"招财"概念错位 |
| "水晶能量层级最高" | 水晶属水，对喜水命主有用；对喜火命主（水克火）反而压能量 |
| "佩戴貔貅 / 麒麟等灵兽招财" | 灵兽属于神煞 / 信仰范畴，本方法论不入主流程；如要佩戴看材质 + 颜色，按本文流程判断 |
| "买什么材质纯靠喜好就好" | 材质长期贴身有累积影响；喜好可决定款式，但材质五行属性不应与用神反向 |

## 四、饮食助运

### 4.1 核心机制

饮食对人的能量影响通过**长期摄入累积**，主要通路：

1. **五味五行**：酸（木）/ 苦（火）/ 甘（土）/ 辛（金）/ 咸（水）
2. **食材五行**：蔬菜 / 肉类 / 水产 / 谷物各有五行倾向
3. **烹饪方式五行**（次要）：生 = 木 / 烧烤煎炒 = 火 / 炖煮 = 水 / 蒸 = 土 / 烟熏 = 金

> **铁律**：饮食助运的边界是**温和、长期、累积**。**任何剧烈的饮食偏向都应优先咨询医生 / 营养师**，不能纯按命理决定。

### 4.2 五行 ↔ 五味映射

| 五行 | 五味 | 典型食物 |
|---|---|---|
| **木** | 酸 | 醋、酸梅、柑橘、山楂、酸奶 |
| **火** | 苦 | 苦瓜、莲心、咖啡、可可、黑巧克力 |
| **土** | 甘 / 甜 | 米饭、糖、蜂蜜、红薯、南瓜、甘蓝 |
| **金** | 辛 / 辣 | 葱姜蒜、辣椒、白胡椒、芥末、薄荷 |
| **水** | 咸 | 盐、酱油、海带、海鱼、味噌 |

### 4.3 五行 ↔ 食材大类映射

| 五行 | 食材类别 | 典型代表 |
|---|---|---|
| **木** | 绿叶蔬菜、芽菜、藻类（深绿）、新鲜水果 | 菠菜 / 生菜 / 西兰花 / 苹果 / 芽菜 |
| **火** | 红色 / 橙色蔬果、辣味、烤制肉类、苦味饮品 | 红椒 / 番茄 / 辣椒 / 烤肉 / 咖啡 |
| **土** | 谷物、根茎类、黄色蔬菜、甘甜水果 | 米饭 / 红薯 / 南瓜 / 玉米 / 香蕉 |
| **金** | 白色蔬菜、菌菇、鱼肉（白肉）、辛辣调料 | 白萝卜 / 白菜 / 鸡肉 / 鱼肉 / 葱姜蒜 |
| **水** | 黑色 / 深色食物、海产、豆类（深色）、咸味 | 黑豆 / 海带 / 黑芝麻 / 海鱼 / 紫菜 |

> 详细映射见 [`lookup_tables.md`](./lookup_tables.md) §十九。

### 4.4 三层框架的应用

#### 第一层 · 命主用神 + 体质判定

饮食与其他维度的关键差异：**还要叠加体质判定**（中医寒热 / 虚实），而不仅是命局用神。

- 命主用神火 + 体质偏寒 → 大胆补火（红 / 辣 / 烤制）
- 命主用神火 + 体质偏热 → 火气虽缺但不能再加热；改用木食（绿叶 / 酸味，木生火）间接补
- 命主用神水 + 体质偏燥 → 大胆补水（咸 / 黑 / 海产）
- 命主用神水 + 体质偏寒 → 水气虽缺但不能再加寒；改用金食（白 / 辛辣，金生水）间接补

> **重要**：**饮食维度必须与体质并看**，不能脱离体质单凭命局推荐。

#### 第二层 · 五行 → 饮食载体

按 §4.2 + §4.3 的映射表组合输出。

#### 第三层 · 时空加权

- **季节**：春季加强木食（顺时令）、夏季加强火食、长夏加强土食、秋季加强金食、冬季加强水食
- **九运**：2024-2043 火运下，整体时代偏火能量；命主全年可适度加大用神方向的食物比例
- **大运 / 流年**：当下大运的用神倾向若与命局基线不同，饮食微调跟随大运

### 4.5 应用场景的能量量级

| 等级 | 场景 | 重点判断 |
|---|---|---|
| ★★★★★ | **日常主食结构** | 主谷物 + 主蛋白方向应符合用神 |
| ★★★★ | **常喝饮品** | 茶 / 咖啡 / 水 / 汤的偏向（每日 1-2 杯持续多年是高强度暴露） |
| ★★★ | **加餐 / 零食 / 调味** | 五味中哪个使用频次最高 |
| ★★ | **重要场合用餐** | 一次性，影响有限 |
| ★ | **偶尔尝鲜** | 影响微小 |

### 4.6 命局矛盾时的饮食取舍

#### 喜火 + 火过盛 + 体质燥热
- **不要补辣 / 烤制 / 苦味** → 火过载
- 改吃绿叶（木生火，但温润）+ 苦中带甘的食物（如苦菊 + 米饭）

#### 喜水 + 水偏弱 + 体质偏寒
- 不要全力补咸 / 寒凉海产 → 寒上加寒
- 改用金食（白色 / 辛温）→ 金生水但本身温热

#### 命局矛盾且体质有特殊需求（怀孕 / 慢性病 / 年龄）
- **优先以医生 / 营养师建议为准**，命理仅作微调参考
- 助运不应凌驾于专业医学建议

### 4.7 常见误区

| 误区 | 纠正 |
|---|---|
| "喜火就要多吃辣" | 火过盛或体质热燥时反而失衡；木食（酸 / 绿叶）是更稳的间接补法 |
| "黑豆补水招财" | 黑豆属水，对喜水命主有益；对忌水命主反而压制 |
| "命主忌火不能吃任何热的食物" | 极端化错误；忌火不等于禁火，只是减少高频 / 过量摄入 |
| "命理学说替代营养学" | 命理是能量层视角，营养学是物质层视角；两者不冲突也不互替，专业医学优先 |
| "佩戴某宝石就能改善饮食吸收" | 跨维度联想，不进入本方法论 |

### 4.8 边界声明

- 健康类问题（消化不良 / 慢性病 / 过敏 / 妊娠）→ **以医生 / 营养师建议为优先**，命理建议只在不冲突的范围内执行
- 极端饮食偏好（断食 / 全肉 / 全素）→ 命理不替代医学评估
- 涉及药食同源的具体方剂 → 不在本文范围

## 五、时辰助运

### 5.1 核心机制

时辰对人的能量影响通过**做关键事时所在的时间窗口**起作用：

1. **十二时辰五行**：每个时辰对应特定五行（与地支同）
2. **用神时辰** vs **当令时辰**：用神时辰 = 个人加分；当令时辰 = 时代加分
3. **关键决定的择时**：起床 / 出门 / 重要会议 / 签约 / 出行的择时偏好

> **铁律**：时辰助运是**偶发场景**的微调，不是日常的重型助运（除起床时间外）。

|---|---|---|---|
| 子时 | 23:00 - 01:00 | 子 | 水 |
| 丑时 | 01:00 - 03:00 | 丑 | 土 |
| 寅时 | 03:00 - 05:00 | 寅 | 木 |
| 卯时 | 05:00 - 07:00 | 卯 | 木 |
| 辰时 | 07:00 - 09:00 | 辰 | 土 |
| 巳时 | 09:00 - 11:00 | 巳 | 火 |
| 午时 | 11:00 - 13:00 | 午 | 火 |
| 未时 | 13:00 - 15:00 | 未 | 土 |
| 申时 | 15:00 - 17:00 | 申 | 金 |
| 酉时 | 17:00 - 19:00 | 酉 | 金 |
| 戌时 | 19:00 - 21:00 | 戌 | 土 |
| 亥时 | 21:00 - 23:00 | 亥 | 水 |

> 详细映射 + 时辰特性见 [`lookup_tables.md`](./lookup_tables.md) §二十。

### 5.3 三层框架的应用

#### 第一层 · 命主用神 → 用神时辰

| 用神 | 推荐时辰 | 避免时辰 |
|---|---|---|
| 木 | 寅、卯（正东，木气最盛） | 申、酉（金克木） |
| 火 | 巳、午（正南，火气最盛） | 亥、子（水克火） |
| 土 | 辰、戌、丑、未（土气分布） | 寅、卯（木克土） |
| 金 | 申、酉（金气最盛） | 巳、午（火克金） |
| 水 | 亥、子（水气最盛） | 辰、戌、丑、未（土克水） |

#### 第二层 · 关键场景择时

| 场景 | 推荐方向 |
|---|---|
| **起床时间** | 用神时辰附近（最高频且累积影响大）；体质有特殊需求按医生为准 |
| **重要决定 / 签约** | 用神时辰；如不可控选当令时辰（2024-2043 优先巳午时） |
| **出门 / 出行** | 用神时辰，避免冲日支的时辰（如日支戌的命主避辰时出门） |
| **谈判 / 面试** | 用神时辰；如对方时间已定，则不强行调整 |
| **创意 / 写作** | 用神是木火则推荐巳午时；用神是金水则推荐子丑时 |
| **运动 / 健身** | 体质 + 用神综合，常人推荐辰时（早晨阳气升发） |

#### 第三层 · 时空加权（与九运 / 大运结合）

- 2024-2043 九运下，**巳午时**有时代加分（火当令）
- 大运用神与命局基线用神有差异时，时辰选择按大运调整

### 5.4 应用场景的能量量级

| 等级 | 场景 | 强度 |
|---|---|---|
| ★★★★ | **起床时间**（每天，长期累积） | 最高 |
| ★★★ | **重要决定 / 签约 / 谈判时辰** | 偶发但高权重 |
| ★★ | **每日重点工作时段** | 与体质 / 工作性质相关 |
| ★ | **日常出门 / 餐时** | 影响微小 |

### 5.5 命局矛盾时的时辰取舍

- 如出生时辰本身是忌神（如喜火命主出生在子时） → 后天通过其他时辰使用做平衡，不是回避（出生时辰不可改）
- 用神时辰是子时 / 亥时（夜间） → 工作场景难以匹配；改用次优用神时辰（如喜水但实际找不到夜间机会，改用金时辰间接补）

### 5.6 常见误区

| 误区 | 纠正 |
|---|---|
| "签约必须挑黄道吉日 + 吉时" | 黄道吉日是择日学专题，不在本文；命主用神时辰是个人维度，两者不替代 |
| "出生时辰决定命运不可改" | 出生时辰是命局组成部分，无法改；助运时辰是后天选择，可改可优化 |
| "凌晨 4 点起床能量最强" | 寅时（03-05）确实是阳气始升，但仅对喜木命主友好；对忌木命主反而打乱节律 |
| "白天工作的人不能选夜间用神时辰" | 用神时辰是"加分"，不是"必须执行"；不可控时不强求 |

## 六、三个维度的整合应用

材质 / 饮食 / 时辰三个维度可同时与颜色 / 方位 / 数字配合，形成完整的助运基线。

### 6.1 一致性原则

同一命主在三个维度的推荐**应方向一致**：

- 用神火 → 材质偏皮革 / 釉瓷 + 饮食偏暖性 / 红色食材 + 起床时辰偏巳午
- 用神水 → 材质偏水晶 / 玻璃 + 饮食偏咸 / 黑色食材 + 起床时辰偏亥子
- 用神矛盾不一致（如材质用木但时辰用金） → 排查是否依据不同（如时辰是出生时辰还是助运时辰）

### 6.2 主载体优先

按 [`zhuyun_overview.md`](./zhuyun_overview.md) §三的能量量级，优先级：

1. **贴身材质 + 日常饮食 + 起床时辰**（高频长期）
2. 居所材质 + 加餐零食 + 重要决定时辰（中频中长期）
3. 偶发饰品 + 偶发餐食 + 偶发出门时辰（低频偶发）

### 6.3 不要过度操作

四维度（含本文三个 + 已有的颜色 / 方位 / 数字）已经能覆盖大部分日常场景。**不要把每一项都精确到极致**，否则陷入"事事择时择物"的过度焦虑。

> **心智锚**：助运是**让命局的优势持续放大、劣势缓慢减损**的工具，不是"必须按规矩执行才能有运"的强制流程。

## 七、流派分歧的处理

### 7.1 水晶归水 vs 归土

- 传统命理（《滴天髓》后世注本）：**水晶归水**（透明流动 + 反射光）
- 矿物学派系：水晶归土（属矿石类）
- **本文采用**：归水（命理传统更连贯）

### 7.2 五味与脏腑对应

- 中医五味：酸入肝 / 苦入心 / 甘入脾 / 辛入肺 / 咸入肾
- 与五行对应：肝木 / 心火 / 脾土 / 肺金 / 肾水
- **本文不展开脏腑层面**，因为这跨入医学范畴；只在**用神层**做食材推荐，并显式建议涉及具体健康问题时咨询专业人士

### 7.3 时辰用 23:00-23:59 vs 00:00-00:59 划分子时（早子时 / 晚子时）

- 古传子时定义：23:00 - 01:00 为整体子时
- 现代部分流派：23:00 - 23:59 为晚子时（属上一日），00:00 - 00:59 为早子时
- **本文采用**：整体子时（23:00 - 01:00），不做早晚区分；除非用户有具体需求

### 7.4 不进入主流程的当代衍生体系

- 七十二候助运、节气微调择时（细节过深，可作辅助参考）
- "玄关风水", 摆件灵兽（信仰层，非命理层）
- 现代"水晶疗愈"、"矿物能量学"（缺乏古典连贯性）
- 商业化"开光符咒"、"加持手串"

> 仲裁规则与 [`zhuyun_overview.md`](./zhuyun_overview.md) §五一致。

## 八、决策流程示例

**示例命主**：丙火日主，生于酉月（财格当令），命局火弱金重，木印缺位。
**用神判定**：用神木火，忌神金水。
**体质**（假设）：偏寒，易疲倦。
**当下时间**：2026 年（九紫离火运第 3 年）。

### Step 1 · 材质推荐

| 等级 | 推荐 | 避免 |
|---|---|---|
| ★★★★★ 贴身 | 紫檀 / 沉香手串、绿翡或黄玉吊坠、皮革手表带 | 银 / 钢手串、水晶项链、珍珠 |
| ★★★★ 随身 | 木质钱包内层、皮包 | 大件金属包扣 |
| ★★★ 居所 | 紫檀沙发把手、釉瓷主灯、暖色皮革靠垫 | 大量水晶摆件、玻璃柜 |

### Step 2 · 饮食推荐

| 等级 | 推荐 | 避免 |
|---|---|---|
| ★★★★★ 主食 | 米饭（中性偏土）+ 红薯（土） + 红辣椒（火）适度 + 绿叶菜（木） | 大量海鱼 / 海带 / 紫菜（水） |
| ★★★★ 饮品 | 红茶 / 黑咖啡 / 姜茶 / 红枣茶 | 大量冰水 / 冷饮 |
| ★★★ 加餐 | 山楂（酸 / 木）+ 黑巧克力（火 + 苦）+ 红色水果 | 大量寒凉水果（西瓜 / 梨） |
| 调料 | 醋（酸 / 木）+ 辣椒少许 | 过咸调味 |

> **体质提示**：因体质偏寒，火 / 木的补给可适度加大，但避免突然大幅辛辣（消化系统承受问题）。

### Step 3 · 时辰推荐

| 场景 | 推荐时辰 | 备注 |
|---|---|---|
| 起床 | 卯时（5-7 点）-辰时（7-9 点） | 早起接收木气 → 木生火 |
| 重要决定 | 巳时（9-11）/ 午时（11-13） | 火当令 + 用神双加分 |
| 签约 | 巳时优先 | 火气助主导能量 |
| 出门 | 卯时 / 巳时 / 午时 | 避免子时 / 亥时（水克火） |
| 创意工作 | 巳午时 | 头脑清醒期 + 火能量 |

### Step 4 · 整合一致性核查

- 材质（木火属性）+ 饮食（暖性 / 红 / 苦）+ 时辰（卯巳午）→ 三维度方向一致 ✓
- 与已有颜色（红橙紫青绿）+ 方位（南 / 东 / 东南）+ 数字（蕴含火数）一致 ✓
- 整体助运基线收敛于"补木火"主轴
