# 助运总论（zhuyun_overview）

> **文档定位**：通用方法论 / 框架性入口。
> 本文不针对任何具体助运维度（数字 / 颜色 / 方位 / 贵人 / 饮食 / 时辰 / 材质…），只回答两个问题：
> 1. 助运是什么、不是什么、能做什么、不能做什么。
> 2. 任何一种助运维度，应该按什么样的统一框架去判断。
>
> 各具体维度的应用见：
> - 数字 → [`shuzi_zhuyun.md`](./shuzi_zhuyun.md)（已建，作为本框架的标杆样例）
> - 颜色 → [`yanse_zhuyun.md`](./yanse_zhuyun.md)
> - 方位 → [`fangwei_zhuyun.md`](./fangwei_zhuyun.md)
> - 贵人方位 → 待补（P2）
> - 材质 / 饰品 / 饮食 / 时辰 → 待补（P3）

---

## 一、助运的定位

### 1.1 能量量级排序（重要 → 不重要）

```
命局本身（先天结构）
   ↓
大运 / 流年（个人时间）
   ↓
风水 / 居住环境（长期物理空间）
   ↓
心性 / 行为模式（认知与行动）
   ↓
助运（数字 / 颜色 / 方位 / 饰品 / 饮食 / 时辰…）   ← 本文范围
```

**助运在最底层**。它是**锦上添花**，不是雪中送炭。如果命局结构本身有重大课题、或大运处于高强度冲克年，助运能起到的作用是**边际优化**而不是逆转。

### 1.2 助运能做什么

- 在用神方向上**持续微补**：每日穿戴、所处空间、贴身物件长期累积，量变到质变
- 在关键场合**临场加成**：面试 / 签约 / 重要洽谈，借助物 / 色 / 方位提供心理与能量上的支持
- 把"忌神"载体降到最低：避免长期暴露在与自身用神相反的能量下

### 1.3 助运不能做什么

- ❌ 改变命局根本结构（八字四柱不会因为换了手机号而改变）
- ❌ 抵消大运 / 流年的高强度冲克（运到了，挡不住，只能减损）
- ❌ 替代医生 / 律师 / 财务顾问的现实建议（健康 / 法律 / 财务议题以现实判断为主）
- ❌ 通过单一变量"逆天改命"（任何宣称"换 X 就能转运"的论断都属于过度承诺）

> **心智锚**：助运是**长期、被动、累积**的辅助手段。期望值要合理。

## 二、通用三层叠加框架

无论助运维度是数字、颜色、方位、还是别的什么，判断流程都遵循同一个三层框架。这个框架最早在 `shuzi_zhuyun.md` 中以"数字"为例完整呈现，本文将其抽象为通用规则。

```
【第一层 · 命主用神】（命理层 → 决定基础方向）
        ↓
【第二层 · 五行映射】（应用层 → 把五行翻译成具体载体）
        ↓
【第三层 · 时空加权】（时间层 + 空间层 → 决定"当下哪些得运"）
        ↓
       助运决策（评级 + 推荐顺序 + 禁忌）
```

### 2.1 第一层 · 命主用神

通过八字静态分析得出命主的**用神 / 喜神 / 忌神**五行。

- 用神 = 命局最缺、最该补的能量
- 喜神 = 用神之外仍有助益的能量
- 忌神 = 已过盛、再补就坏的能量
- 闲神 = 中性

判断逻辑详见 [`basics.md`](./basics.md) §五。

> **铁律**：**没有用神判定，不进助运决策**。脱离命主谈助运，就是数字能量学一类"对所有人通用"的伪体系。

### 2.2 第二层 · 五行映射

把第一层的五行翻译成具体维度的载体：

| 维度 | 五行 → 载体的映射来源 |
|---|---|
| 数字 | 后天洛书九宫（1坎水 / 2坤土 / 3震木 / 4巽木 / 5中土 / 6乾金 / 7兑金 / 8艮土 / 9离火） |
| 颜色 | 五行色系（木青绿 / 火红橙紫 / 土黄棕 / 金白银金 / 水黑蓝灰） |
| 方位 | 后天八卦九宫（北水 / 南火 / 东木 / 西金 / 中土 + 四隅） |
| 饮食 | 五味（木酸 / 火苦 / 土甘 / 金辛 / 水咸） |
| 材质 | 五行物质（木为木材 / 火为皮革陶瓷 / 土为玉石陶土 / 金为金属 / 水为水晶玻璃） |
| 时辰 | 十二地支时辰（与五行直接绑定） |

具体映射表沉到 [`lookup_tables.md`](./lookup_tables.md)，本层只做"查表"。

### 2.3 第三层 · 时空加权

第二层得出的"理论上属于某五行的载体"还要再过一道时空滤镜：

- **时间层（三元九运）**：当下哪个五行在 20 年大周期里得令？2024-2043 是九紫离火运，火得令；同时木生火，木有助旺加分。详见 [`sanyuan_jiuyun.md`](./sanyuan_jiuyun.md)。
- **空间层**（仅适用于方位类维度）：当下九运里哪个方位是旺方、哪个是衰方？详见 [`fangwei_zhuyun.md`](./fangwei_zhuyun.md)。
- **个人大运**（如果命主当下大运的偏向与命局基线用神有差异）：以**大运 > 三元九运**优先，因为个人时空 > 时代时空。

加权后，每个候选载体得到一个综合评级（如 ★★★★★ → ★）。

### 2.4 框架的两条铁律

1. **三层缺一不可**：只看用神不看时空 = 错过当下加权；只看九运不看用神 = 退化为"对所有人通用"的伪体系；只看五行映射 = 缺乏命理基础。
2. **大运 > 三元九运 > 命局基线**（仅在三者方向冲突时）：如命局基线喜火，但当下走到一步火过旺的运，则该运十年内"补火"反而过度，"补木 + 调候"才对。这种调整由 [`prompts/yearly_focus.md`](../prompts/yearly_focus.md) 在大运层处理。

## 三、主载体 vs 辅助载体（能量量级排序）

不是所有助运维度的强度都一样。同样是"补火"，每天贴身的红色内衣比偶尔挂的红色装饰画作用大得多。统一排序如下：

| 等级 | 类型 | 典型例 | 强度 |
|---|---|---|---|
| ★★★★★ | **贴身长期** | 内衣 / 贴身首饰 / 手机壳 / 床品 / 枕头 | 最高 |
| ★★★★ | **居所大件** | 主墙色 / 沙发 / 床架 / 大件家具 / 主灯 | 高 |
| ★★★ | **日常移动** | 外套 / 包 / 鞋 / 钱包 / 车 / 手机号 | 中高 |
| ★★ | **偶发场合** | 重要会议穿搭 / 签约日座位 / 礼物色 | 中 |
| ★ | **装饰偶遇** | 装饰画 / 短期摆件 / 一次性场合用品 | 低 |

**判断顺序**：选载体优先从★★★★★往下补，避免本末倒置（不要花大力气调一幅装饰画，却让床品长期是忌神色）。

## 五、流派分歧的统一处理方针

不同流派对同一维度可能给出不同结论。本仓库的**统一仲裁规则**：

| 冲突类型 | 仲裁原则 |
|---|---|
| 后天洛书 vs 先天河图 | **以后天洛书为准**（"用"层高于"体"层；河图仅作底层推算如纳音、五运六气） |
| 后天洛书 vs 天干配数 | **以后天洛书为准**（应用层高于命理速查；最典型冲突是"9 在洛书=火 / 在天干配数=水"） |
| 命主大运 vs 当下九运 | **以命主大运为准**（个人时空 > 时代时空） |
| 命主用神 vs 当代主流能量 | **以命主用神为准**（命理层 > 时代层） |
| 当代衍生体系（数字能量学 / 数字磁场表 / "彩虹能量"色卡等） | **不进入主流程**；可作组合粗筛参考，但不能作为主判据 |
| 神煞贵人方位 vs 用神贵人方位 | **互补不互排**（神煞主"遇人型"贵人，用神方位主"得力型"贵人；详见 P2 `zhuyun_guiren.md`） |

> 上述规则与 `shuzi_zhuyun.md` §七的数字流派仲裁完全一致，是同一套原则在不同维度上的应用。

## 六、通用决策流程模板

下面是一份**任何助运维度都可套用的决策流程**。具体到某一维度时，第二步换查表、第三步换该维度的时空加权表即可。

### Step 1 · 命主用神判定

输入：完整命局（八字四柱 + 大运 + 当前所处大运）

输出：
- 命局基线用神 / 喜神 / 忌神
- 当前大运对基线的微调（是否需要临时调整方向）

> 如未做过用神判定 → 先转 [`prompts/full_analysis.md`](../prompts/full_analysis.md) 的 Step 2，得到用神结论再回来。

### Step 2 · 五行 → 载体映射

按 [`lookup_tables.md`](./lookup_tables.md) 把用神 / 忌神翻译成该维度的具体候选值（数字 / 颜色 / 方位 / …）。

### Step 3 · 时空加权

- 用 [`sanyuan_jiuyun.md`](./sanyuan_jiuyun.md) 给每个候选值加上当下九运的时态（当令 / 未来 / 退气 / 衰气 / 死气）
- 方位类维度还要叠加九运的方位旺衰（详见 `fangwei_zhuyun.md`）

### Step 4 · 综合评级

按"用神得分 + 时空加权"得出每个候选值的综合评级（★★★★★ → ★）。

### Step 5 · 落到载体优先级

按本文 §三的"主载体 vs 辅助载体"排序，选出该等级载体里评级最高的若干候选。

### Step 6 · 输出

- 推荐清单（按评级降序）
- 禁忌清单（忌神 + 衰气双重负向的载体）
- 风险标注（如某候选用神达标但九运衰气，应说明"个人加分 + 时代不加分"，命主自行权衡）

> **诚实纪律**：当用神与九运冲突时，**显式说明冲突**，不要倒推合理化某一方。命主有权选择"按个人用神"或"按当下时态"，但必须知道这是个权衡，不是单一最优解。

## 七、不进入助运主线的内容

为保持 methodology 主线的严肃度，以下内容**不进**助运决策流程，仅在附录 / 辨析中提及（如有）：

- 数字能量学 / 易经数字密码 / 手机号磁场表（详见 `shuzi_zhuyun.md` 附录 C）
- "彩虹能量"色卡 / 现代色彩心理学派生体系（缺乏命理基础）
- 西方占星 / 塔罗等异源体系（不混搭）
- 缺乏古典文献依据的"幸运石 / 招财动物 / 吉祥物"现代附会
- 涉及医疗 / 投资 / 法律的具体决策（助运只做能量层提示，决策回到现实专业建议）

## 八、术语速查

| 术语 | 释义 |
|---|---|
| 用神 | 命局最缺、最该补的能量 |
| 喜神 | 用神之外仍有助益的能量 |
| 忌神 | 已过盛、再补就坏的能量 |
| 三层叠加 | 用神（命理）+ 五行映射（应用）+ 时空加权（时间 / 空间） |
| 主载体 | 贴身长期使用的助运载体（衣物、首饰、床品、手机壳等） |
| 辅助载体 | 偶发或短期接触的助运载体（装饰、礼物、一次性场合用品） |
| 当令 | 当前 20 年三元九运里的主流五行（2024-2043 = 火） |
| 退气 | 上一个 20 年的主流五行，余气未散仍可用 |
| 衰气 / 死气 | 远离当令的五行，能量较弱 |

## 九、版本与引用约定

- 本总论是 `methodology/zhuyun_*.md` 系列的入口；各专题文件应在文首引用本文确立的"三层叠加框架"。
- 修订本总论时谨慎 —— 任何对"三层叠加"的调整都会传导到所有专题。
- prompts 引用助运内容时，应优先指向具体专题（颜色 → `yanse_zhuyun.md`），仅在需要解释"为什么这么算"时回到本文。
