# 贵人方位（zhuyun_guiren）

> **文档定位**：助运维度专题。本文是 [`zhuyun_overview.md`](./zhuyun_overview.md) 三层叠加框架在**贵人方位**维度的具体应用。
>
> 本文与 [`fangwei_zhuyun.md`](./fangwei_zhuyun.md) 是同级专题：
> - `fangwei_zhuyun.md` 关注**自身能量补给**（居所 / 床头 / 办公朝向 / 城市选择）—— 答"我应该在哪个方位生活"
> - `zhuyun_guiren.md` 关注**贵人来自何方**（求人 / 谈判 / 合作 / 师长 / 资源）—— 答"我应该向哪个方位求助"
>
> 两文不重复，请按问题类型选其一或并用。

## 一、贵人方位的两套体系

中国传统命理对"贵人方位"有**两套并行体系**，回答的是**不同问题**，必须先分清才不会糊在一起：

| 体系 | 别名 | 回答的问题 | 性质 |
|---|---|---|---|
| **神煞天乙贵人** | 天乙、玉堂贵人 | "谁会来帮我？从哪个方位来？" | **遇人型贵人**（被动相遇 + 关键时刻雪中送炭） |
| **用神方位贵人** | 用神方、喜神方 | "向哪个方位求助，能量上更顺？" | **得力型贵人**（主动求人 + 长期能量加成） |

> **铁律**：两套体系**互补不互排**。一份完整的贵人方位推演必须**两套都给**，并显式说明各自的适用场景，不能只给一套就完事，也不能糊在一起说。

### 1.1 为什么是两套

- **神煞体系**：从日干起，是命主**先天自带**的贵人位（即"哪些方位的人天然会照应你"）。地支是"人 / 关系"层面的。
- **用神方位**：从命局结构起，是命主**结构性需要补给**的方位（即"哪些方位的能量对你这个命局有利"）。方位是"能量 / 气场"层面的。

两套体系对同一命主**经常给出不同方位**，这不是冲突，而是**两个独立维度**：神煞贵人的人，可能恰好在用神方位；也可能在忌神方位。两者并存，互不冲突。

## 二、神煞天乙贵人

### 2.1 起法（按日干）

天乙贵人按**日干**起，每个日干对应**两个地支**作为贵人位（极少数派别按年干起，本文以日干起为主线，详见 §八流派分歧）。

| 日干 | 天乙贵人地支 | 口诀 |
|---|---|---|
| 甲、戊、庚 | 丑、未 | 甲戊庚牛羊 |
| 乙、己 | 子、申 | 乙己鼠猴乡 |
| 丙、丁 | 亥、酉 | 丙丁猪鸡位 |
| 壬、癸 | 卯、巳 | 壬癸兔蛇藏 |
| 辛 | 寅、午 | 六辛逢虎马 |

> 详细速查表见 [`lookup_tables.md`](./lookup_tables.md) §十六。

### 2.2 地支 → 方位映射

天乙贵人查出的是**地支**，要转成**方位**才能落地为助运决策：

| 地支 | 方位 | 五行 |
|---|---|---|
| 子 | 正北 | 水 |
| 丑 | 东北偏北 | 土 |
| 寅 | 东北偏东 | 木 |
| 卯 | 正东 | 木 |
| 辰 | 东南偏东 | 土 |
| 巳 | 东南偏南 | 火 |
| 午 | 正南 | 火 |
| 未 | 西南偏南 | 土 |
| 申 | 西南偏西 | 金 |
| 酉 | 正西 | 金 |
| 戌 | 西北偏西 | 土 |
| 亥 | 西北偏北 | 水 |

> 这个十二地支方位划分比 [`fangwei_zhuyun.md`](./fangwei_zhuyun.md) 的八卦九宫**更细**（八卦九宫只到八方 + 中宫；这里到十二位）。
>
> 详细对照见 [`lookup_tables.md`](./lookup_tables.md) §十七。

### 2.3 双支判定（大多数日干有两个贵人位）

除辛日干外，每个日干都有**两个**贵人地支。如何选用：

- **阳贵 / 阴贵之分**：传统说阳贵主"白昼 / 公开 / 正式场合"，阴贵主"夜晚 / 私下 / 非正式场合"。具体到方位：
  - 甲日：丑（阳贵，东北）/ 未（阴贵，西南）
  - 戊日：丑（阳贵，东北）/ 未（阴贵，西南）
  - 庚日：丑（阳贵，东北）/ 未（阴贵，西南）
  - 乙日：申（阳贵，西南）/ 子（阴贵，正北）
  - 己日：申（阳贵，西南）/ 子（阴贵，正北）
  - 丙日：酉（阳贵，正西）/ 亥（阴贵，西北）
  - 丁日：酉（阳贵，正西）/ 亥（阴贵，西北）
  - 壬日：卯（阳贵，正东）/ 巳（阴贵，东南）
  - 癸日：卯（阳贵，正东）/ 巳（阴贵，东南）
  - 辛日：寅（阳贵，东北）/ 午（阴贵，正南）
- **实操简化**：在大多数日常助运决策中，**两支都列为有效贵人位**，命主可结合具体场景择一。
- **特殊情况**：当命主已透露具体场景（白天的会议 vs 夜间的应酬），再按阳贵 / 阴贵筛选。

### 2.4 天乙贵人在四柱中的"出现意义"

如果天乙贵人地支**已经出现在命主自己的四柱里**（如日干甲见原局有丑或未），意义有变：

| 出现位置 | 含义 |
|---|---|
| 年柱 | 自小有长辈型贵人 / 家世背景照拂 |
| 月柱 | 兄弟姐妹 / 同事 / 师长贵人显现 |
| 日支 | 配偶或亲密关系即贵人 |
| 时柱 | 子女 / 晚辈 / 下属贵人显现 |
| 流年遇 | 当年遇贵 / 提点 / 贵人施援 |
| 大运遇 | 该十年贵人运通畅 |

**特别提醒**：贵人在原局**坐空亡**或**逢冲克**，则贵人之力大打折扣甚至反成阻力（"贵人逢冲，反目成仇"为传统断语，本文不取宿命论描述，只标注"该贵人位在此命主身上**力量减半**"）。

## 三、用神方位贵人

用神方位贵人继承自 [`fangwei_zhuyun.md`](./fangwei_zhuyun.md) 的"用神方位"概念，但应用场景不同：

- 在 `fangwei_zhuyun.md` 里，用神方位用于"我应在何处生活"
- 在本文里，用神方位用于"**向何方求助 / 找谁合作 / 哪个方位的人际关系更顺**"

### 3.1 五行 → 方位（用神层）

| 用神五行 | 主贵人方位 | 辅贵人方位 |
|---|---|---|
| 木 | 东（震） | 东南（巽） |
| 火 | 南（离） | 东 / 东南（木生火） |
| 土 | 西南（坤） / 东北（艮） | 中宫 |
| 金 | 西（兑） / 西北（乾） | 西南 / 东北（土生金） |
| 水 | 北（坎） | 西 / 西北（金生水） |

### 3.2 当下九运（2024-2043）的加权

直接复用 [`fangwei_zhuyun.md`](./fangwei_zhuyun.md) §三的方位旺衰对照。**特别注意**：

- 当用神方位 = 九运旺方（如喜火命主的南方）→ 双重加分，向该方位求人 / 找资源**事半功倍**
- 当用神方位 = 九运衰方（如喜金命主的西方）→ 用神层加分但时代衰，找该方位的人需要更精准（不能广撒网）

### 3.3 用神方位贵人的画像

不同用神对应的"贵人画像"有典型偏向：

| 用神 | 贵人典型画像 |
|---|---|
| **印星**（生我者）| 师长 / 长辈 / 学者 / 公职人员 / 提供资源支持的人 |
| **比劫**（同我者）| 朋友 / 同辈 / 合伙人 / 团队战友 |
| **食伤**（我生者）| 学生 / 晚辈 / 创意伙伴 / 表达型贵人 |
| **财星**（我克者）| 客户 / 供应商 / 实务型贵人 / 商业伙伴 |
| **官杀**（克我者）| 上级 / 评审 / 制定规则的人 / 给压力同时提供机会的人 |

> 用神方位 + 用神画像组合使用，决策粒度更细。

## 四、两套体系的整合

### 4.1 三种关系矩阵

天乙贵人方位 vs 用神方位，每一对组合的实操含义：

| 天乙贵人 | 用神方位 | 关系判定 |
|---|---|---|
| **同方位** | **同方位** | **强贵人位**（双系统共指）：求人优先方向，长期合作伙伴亦优先此方 |
| **同方位** | **不同方位** | **遇人型主导**：天乙方位主"会遇到帮你的人"；用神方位主"长期能量补给"；两者各管一头 |
| **不同方位** | **不同方位** | **互补关系**：贵人方位是"短期 / 偶发"决策，用神方位是"长期 / 居所 / 办公"决策 |
| 与忌神方位重合 | — | 该方位的人虽是贵人，但相处时需避免"对方能量盖过自己"（详见 §4.3） |

### 4.2 不同场景的优先级

| 场景 | 优先体系 |
|---|---|
| 求人办事（一次性） | **天乙贵人方位**为主 |
| 重要谈判 / 签约（短期高强度） | 两者并用，座位 / 朝向用用神方位，对方人选用天乙方位筛选 |
| 寻找长期合作伙伴 | **天乙贵人方位**为主，用神方位筛选 |
| 寻找导师 / 师长 / 行业前辈 | **天乙贵人方位**为主（长辈型贵人是天乙的强项） |
| 选投资人 / 大客户 | 两者并重，神煞方位列候选，用神方位排序 |
| 入职公司 / 平台选择 | **用神方位**为主（涉及长期居所变迁） |
| 长期居所 / 办公 | **用神方位**为主（参 `fangwei_zhuyun.md`） |

### 4.3 当贵人方位重合忌神方位（特殊情况）

例：庚日干（天乙贵人在丑、未 = 东北 / 西南）但喜木火（忌金土）→ 西南即是天乙贵人位（土），又是忌神方位。

**处理**：
1. **该方位的人仍是命主天然贵人**（先天体系不会因后天结构改变）
2. 但**与该方位贵人长期共处时，命主能量会被克泄**（如在西南方位的公司长期工作，土泄火耗）
3. **解法**：把该方位的人当作"项目型 / 短期顾问型"贵人，借力但不依附；不长期在该方位驻扎

## 五、应用场景的能量量级

| 等级 | 场景 | 重点判断 |
|---|---|---|
| ★★★★★ | **关键节点求人**：重要面试 / 项目立项 / 高难度谈判前找谁支持 | 双系统重合时优先；不重合时按场景选 |
| ★★★★ | **长期合作伙伴 / 导师选择** | 天乙贵人 + 用神方位双向筛选 |
| ★★★ | **重要会议座位 / 入座方向** | 用神方位为主（自身气场）；面向贵人方位为辅 |
| ★★ | **日常人脉拓展** | 在贵人方位多走动，扩展该方向的弱关系 |
| ★ | **临时求助 / 偶发请求** | 优先选贵人方位的联系人，差异不大时按其他因素决定 |

## 六、应用场景的具体决策

### 6.1 关键节点求人

**判断流程**：
1. 列出可求助的所有候选人，标注每人所在方位（地理位置 / 籍贯 / 公司位置 / 主要活动方位）
2. 优先选**天乙贵人方位 + 用神方位**双重重合的候选人
3. 次选只在天乙贵人方位的候选人
4. 再次选只在用神方位的候选人
5. 兜底：选与命主关系最深的人（关系深度 > 方位玄学）

**心智锚**：方位是"加成项"，不是"决定项"。关系深度始终高于方位匹配度。

### 6.2 重要会议 / 谈判座位

**坐向**：自己的**坐向**（背靠方）应是用神方位的对侧，使**面向**朝用神方位（同 `fangwei_zhuyun.md` §6.3）。

**进一步**：会议桌的对手 / 合作方所在方位，理想情况是**天乙贵人方位**（即对方坐在你的天乙方位上）。这种安排不一定可行，但**主动选择会议地点 / 房间布局**时可纳入考虑。

**示例**：丙日干（天乙贵人在亥、酉 = 西北 / 正西），用神火 → 自己面南，理想下对方坐在你的西 / 西北侧。

### 6.3 寻找导师 / 师长

天乙贵人在**长辈 / 师长型贵人**的命中率较高，因为这是天乙的传统含义。

**判断流程**：
1. 列出候选导师，按其"主要活动方位"标注
2. 候选导师在**天乙贵人方位**的优先
3. 候选导师对应**印星画像**（学者 / 资深前辈 / 公职 / 学界）的优先
4. 双条件都满足的候选导师 = 长期师承潜质最高

### 6.4 寻找长期合作伙伴

**判断流程**：
1. 候选合作方按方位排序：天乙贵人方位 > 用神方位 > 中性方位 > 忌神方位
2. 但**关键是"互补"**：候选合作方的命局如能与命主互补（比如命主缺火、对方为火多 / 喜表达型），则方位作为加成项
3. 警惕：候选方在命主**忌神方位且为忌神画像**（如命主忌官杀但对方是强势上级型）的合作 → 短期可能高效，长期会被消耗

### 6.5 投资人 / 大客户选择

- **天乙贵人方位**：投资人 / 客户来自此方位时，相处中"天然合拍 / 提点指点 / 关键时刻援手"概率高
- **用神方位**：长期能量配合好；适合**长期合作型客户**
- **忌神方位但天乙贵人方位**：可做"重要项目 / 短期高难度合作"，避免长期股权绑定

### 6.6 平台 / 公司入职选择

参 [`fangwei_zhuyun.md`](./fangwei_zhuyun.md) §6.6。本文不重复。重点：

- 长期入职选择以**用神方位**为主轴（涉及居住地、办公场所）
- 但**直接领导 / 直属老板**的方位匹配度可单独检验：领导在天乙贵人方位 = 有"被赏识 / 被提拔"的天然加成

## 七、决策流程示例

**示例命主**：丙火日主，生于酉月（财格当令），命局火弱金重，木印缺位。
**用神判定**：用神木火，忌神金水。
**天乙贵人**（丙日干）：亥（阴贵，西北）/ 酉（阳贵，正西）。
**当下时间**：2026 年（九紫离火运第 3 年）。

### Step 1 · 双系统贵人方位

| 体系 | 方位 | 加权 |
|---|---|---|
| **天乙贵人** | 亥（西北）/ 酉（正西） | 神煞固定，不受九运调整 |
| **用神方位** | 南（火） / 东 / 东南（木） | 南方九运双加分；东 / 东南木生火加分 |

> **观察**：本命主天乙贵人方位（西北 / 正西）与用神方位（南 / 东 / 东南）**完全不重合**。这是常见情况——两套体系正交。

### Step 2 · 不同场景的贵人选择

| 场景 | 优先方位 | 说明 |
|---|---|---|
| 找导师 / 师长 | **西北 / 正西** | 天乙贵人方位主导；长辈型贵人多在此方 |
| 重要谈判（一次性） | **西北 / 正西** | 找此方位的中间人 / 介绍人最得力 |
| 长期合作伙伴 | **西北 / 正西**（候选）+ **南 / 东南**（命局加分） | 神煞方位先筛，用神方位再排序 |
| 长期居所 / 办公 | **南 / 东 / 东南**（用神方位为主） | 不应为追"贵人方位"而搬到忌神方位 |
| 入职公司选择 | **南 / 东 / 东南**（用神方位） | 但选 boss 时优先西北 / 正西出身 |
| 重要会议座位 | 自己面南，对方坐西 / 西北 | 自身能量 + 贵人方位双照应 |

### Step 3 · 警示

天乙贵人在**西北 / 正西**——这恰好是**忌神方位**（金）。处理：

- 该方位的人**仍是天然贵人**，关键时刻会援手
- 但**避免长期驻扎该方位**（如不要为追这个贵人位而搬到西部城市）
- 与该方位贵人保持**项目型 / 顾问型**关系，不长期共处办公空间

### Step 4 · 行动建议

- **2026 年**重点拓展：广州 / 深圳出身的同行（南方 + 用神 + 九运三重加分），同时深耕"曾经认识的西北 / 西部出身的师长型人物"（天乙贵人方位）
- **寻找导师**：优先西北 / 西部出身的行业前辈
- **重要谈判前**：寻找一位西北 / 正西方位的中间人作引荐
- **长期居所**：南方 / 东南方城市；不为天乙贵人方位而搬西部

## 八、流派分歧的处理

### 8.1 日干起 vs 年干起

| 派别 | 主张 | 本文取舍 |
|---|---|---|
| 主流（《三命通会》《滴天髓》后世注本） | **按日干起** | **本文采用** |
| 部分古法（早期《珞琭子》系派） | **按年干起** | 不采用，但承认其存在 |

**理由**：日柱代表命主自身，按日干起的天乙贵人在大多数验证案例里命中率更高；年干起多数情况退化为"族群级别的贵人"，对个体命主参考价值有限。

### 8.2 阳贵 / 阴贵的实操度

- 阳贵 / 阴贵的传统含义（白昼 / 黑夜、公开 / 私下）在现代生活中边界已模糊
- 实操时**两支同列为有效贵人方位**；只有当用户提供具体场景（如"夜间饭局"）时再用阳阴细分
- 不强求每次都做阴阳划分

### 8.3 神煞与扶抑用神冲突时的处理

某些命主天乙贵人位恰好是忌神方位（如本文 §七示例）。这种冲突的解读：

- **神煞贵人不变**：神煞是先天结构层，不因用神调整
- **决策上**：贵人位人脉照常用，但避免长期驻扎该方位（不把人脉资源 ≠ 居所）
- **不试图"调和"**：硬要通过其他助运手段（颜色 / 数字）"修正"贵人方位的忌神属性是过度操作；接受两套体系本就正交，分开用即可

### 8.4 不进入主流程的当代衍生体系

- "招贵人手串"、"招贵人符咒"等商品化产品 → 不进入本方法论
- "四大贵人"派别（除天乙外，加文昌、太极、福星等的复合体系）→ 流派分歧大，本文只用天乙
- "桃花贵人 / 偏财贵人" 等基于桃花、财星的衍生体系 → 不进入本文（需要时单独处理）

> 仲裁规则与 [`zhuyun_overview.md`](./zhuyun_overview.md) §五一致。
