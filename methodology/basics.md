## 一、什么是八字 / 命局

"八字"是用**八个字**（四组天干地支）记录一个人出生的年、月、日、时。例如某人生在 `壬午年 己酉月 丙戌日 丙申时`，这八个字就是他的命局。

| 柱 | 含义 |
|---|---|
| 年柱（年干 + 年支） | 祖辈 / 早年环境 / 远方 / 大社会背景 |
| 月柱（月干 + 月支） | 父母 / 家庭 / 中年事业 / 月令气场（最旺） |
| 日柱（日干 + 日支） | **日干 = 命主本人**；日支 = 配偶宫、夫妻位 |
| 时柱（时干 + 时支） | 子女 / 晚年 / 远方 / 行动方向 |

**日主 = 八字中的"我"**。命局所有分析都以日主为核心。

> 例：`丙戌日` 的人，"丙火" 就是这个人的本质属性。所有用神判断都从"丙火日主"出发。

## 二、十神：十种能量角色

"十神"不是十个神，是**十种能量角色**，描述外来能量与日主的关系。

### 2.1 十神快速对照表

| 十神 | 与日主的关系 | 现实角色 / 能量 |
|---|---|---|
| **比肩** | 与我同性同气 | 同辈、合伙人、自我能量、行动力 |
| **劫财** | 与我同气但异性 | 兄弟姐妹、竞争者、消耗型同伴、冲动消费 |
| **食神** | 我所生且温和 | 温和的创作、艺术、孩子、表达 |
| **伤官** | 我所生但激烈 | 批判性思考、独立创作、不守规则、灵感 |
| **偏财** | 我克者但流动 | 副业、机会型收入、流动资源 |
| **正财** | 我克者且稳定 | 正式工资、固定资产 |
| **七杀** | 克我但强烈 | 巨大压力、目标驱动、考验、女命的伴侣（对峙型） |
| **正官** | 克我但温和 | 规则、正式职位、女命的伴侣（温和型）、社会身份 |
| **偏印** | 生我但偏门 | 非主流学问、玄学 / 灵性、独特天赋 |
| **正印** | 生我者 | 母亲、师长、学历、精神滋养、保护 |

> 精确的"五种关系 × 阴阳同异 → 十神"推导矩阵见 `lookup_tables.md`。

### 2.2 简化记忆口诀

> "**印**滋养我，"**比劫**" 同我， "**食伤**" 我生， "**财**" 我克， "**官杀**" 克我"。

### 2.3 阴阳同性 vs 异性

每个十神又分**阴阳**：
- 同性相见 → 偏（偏印、比肩、食神、偏财、七杀）
- 异性相见 → 正（正印、劫财、伤官、正财、正官）

阴阳的差异决定能量的"刚柔"：偏更刚烈、正更温和。

## 三、五行的现实含义

五行是 **木 / 火 / 土 / 金 / 水**。它们之间有 **生 / 克** 关系：

```
生：木 → 火 → 土 → 金 → 水 → 木（循环）
克：木 → 土，土 → 水，水 → 火，火 → 金，金 → 木
```

### 3.1 五行的人生意义对照（按不同日主而变）

不同日主，同一五行的"现实意义"完全不同。下面以 **丙火日主** 为例，但其他日主可类推：

| 五行 | 对丙火日主是什么十神 | 现实代表的能量 |
|---|---|---|
| 木 | 印星（生我） | 学习 / 师长 / 精神支撑 |
| 火 | 比劫（同我） | 自我能量、行动力、表达欲 |
| 土 | 食伤（我生） | 输出、创作、表达成果 |
| 金 | 财星（我克） | 现实资源、工作回报、钱 |
| 水 | 官杀（克我） | 外部压力、规则、伴侣议题（女命） |

> 同样的"水"，对**癸水日主**就是"自我"，对**戊土日主**就是"妻 / 财"。所以阅读分析时一定要先看日主。

### 3.2 季节与五行

每个季节有当令的五行——出生在该季节，对应五行能量最旺。

- 春季（寅卯辰月）当令 **木**：草木生发
- 夏季（巳午未月）当令 **火**：阳气最盛
- 秋季（申酉戌月）当令 **金**：收敛肃杀
- 冬季（亥子丑月）当令 **水**：寒冷潜藏
- 四季月（辰戌丑未）当令 **土**：转换枢纽

**月支**最重要，它代表"出生季节"，对日主能量影响最大。

> 月支与季节五行的精确对应表见 `lookup_tables.md`。

## 四、合冲刑害伏吟

每一步大运 / 流年的天干地支，会与原局发生互动。互动剧烈程度从轻到重：

| 互动 | 通俗解释 | 体感 |
|---|---|---|
| **合**（六合 / 三合 / 半合） | 两个或多个能量被拉到一起、绑定 | 关系或局面被联动，可能转化方向 |
| **冲**（六冲） | 两个能量直接对抗 | 剧烈变动、被迫面对、突变 |
| **刑** | 持续的摩擦、损耗 | 暗伤、慢性问题、关系不和 |
| **害**（六害） | 暗中损害 | 不易察觉的损耗、关系阴影 |
| **伏吟** | 同字重叠（运的字 = 原局某字） | 旧模式重演、能量复刻 |
| **反吟** | 与原局某字六冲且天干同 | 强烈对抗、情绪剧烈波动 |

冲是术数里**变动信号最强**的一类，往往对应居住地、关系、工作、健康的实质性变化。
刑没有冲那么剧烈，但会带来"持续性的摩擦"。
半合的力量约为三合的一半。

> 具体的地支六合 / 三合 / 半合 / 六冲 / 三刑 / 六害组合，见 `lookup_tables.md`。

## 五、用神 / 喜神 / 忌神

这是命理判断的**核心**。

| 概念 | 定义 | 通俗理解 |
|---|---|---|
| **用神** | 命局最缺、最需要补的能量 | "我最该补的" |
| **喜神** | 用神之外仍有助益的能量 | "次要补给" |
| **忌神** | 命局已过盛 / 再加就坏的能量 | "我最该避的" |
| **闲神** | 既不利也不害的中性能量 | "无所谓" |

### 5.1 用神判断的核心逻辑

简化版：
1. **看身强身弱**：日主在月令中是否得令？四柱中印比够不够？
2. **身弱**：用神是"扶身"的（印 / 比劫）；忌神是"耗身"的（财 / 官杀 / 食伤太过）
3. **身强**：用神是"耗身"的（食伤 / 财 / 官杀）；忌神是"扶身"的
4. **调候**：寒局喜火、热局喜水、燥局喜润、湿局喜燥（与扶抑结合判断）

> 用神判断是技术活，不是数清五行个数那么简单。

### 5.2 大运用神可能调整

命局用神是"体"，**大运 / 流年用神** 在大体框架内可能"微调"：
- 比如某人命局喜火，但走到一步火太旺的运 → 那十年内"补火"反而过度，"补木 + 调候"才对
- 这种"大运层面的微调"是流年分析的核心内容之一

## 六、大运 / 流年

### 6.1 大运（10 年一段）

以**月柱**为起点，按命主性别 + 年干阴阳决定排运方向（顺排 / 逆排），每 10 年一步。

排运方向规则：
- 阳男 / 阴女 → 顺排
- 阴男 / 阳女 → 逆排

每个人一生通常分析 8 步大运（约 80 年），覆盖人生主体阶段。

> 注：本仓库不让 AI 排盘。具体大运序列由专业排盘软件给出，AI 解读时直接读取 `charts/{chart_id}/static_chart.json` 中已排好的大运。

### 6.2 流年（每年一变）

每年的天干地支按六十甲子循环。流年与大运、原局发生新的互动 → 形成"年度命题"。

> 跨越 180 年的"三元九运"专题（个人命局以外的时代主流能量）见 `sanyuan_jiuyun.md`。

| 岁运并临 | 流年柱与大运柱完全相同的特殊年份 |
