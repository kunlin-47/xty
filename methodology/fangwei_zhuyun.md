> **文档定位**：助运维度专题。本文是 [`zhuyun_overview.md`](./zhuyun_overview.md) 三层叠加框架在**方位维度**的具体应用。

## 一、方位助运的核心机制

方位影响人的能量主要通过三条通路：

1. **空间持续暴露**：长期居所 / 办公位的朝向决定了视觉、采光、声场、磁场的累积影响
2. **五行能量类比**：传统命理将八卦九宫与五行对应，命主用神所属五行的方位是该五行能量的"空间补给点"
3. **三元九运的方位旺衰**：每 20 年大运周期里，不同方位的能量盛衰会轮转（与色系类比，但方位是固定参照系）

第二、三条是助运体系的工作机制。

> **铁律**：**先有用神判定，再选方位**。脱离命主谈"哪个方位旺财 / 旺事业"是商业话术，不属于本方法论。

## 三、三层框架在方位维度的应用

### 3.1 第一层 · 命主用神

输入命主用神 / 喜神 / 忌神五行（同 `yanse_zhuyun.md` §3.1）。

### 3.2 第二层 · 五行 → 方位映射

按 §二查表得出推荐方位与避免方位。

例（喜木火）：推荐 东 / 东南（木）+ 南（火）；避免 西 / 西北（金）+ 北（水）。
例（喜土火）：推荐 西南 / 东北（土）+ 南（火）+ 中宫；避免 东 / 东南（木克土）。

### 3.3 第三层 · 时空加权（当下九运的方位旺衰）

2024-2043 九紫离火运的方位旺衰：

| 方位 | 八卦 | 五行 | 当下九运时态 | 加分 / 减分 |
|---|---|---|---|---|
| **南** | 离 9 | 火 | **当令** | **大幅加分** |
| 北 | 坎 1 | 水 | 未来生气（下一运） | 加分 |
| 西南 | 坤 2 | 土 | 未来生气 | 加分 |
| 东 | 震 3 | 木 | 死气但生火 | 加分（生火） |
| 东南 | 巽 4 | 木 | 死气但生火 | 加分（生火） |
| 中宫 | 中 5 | 土 | 死气 | 不加 |
| 西北 | 乾 6 | 金 | 死气 | 减分 |
| 西 | 兑 7 | 金 | 衰气（七运 1984-2003） | 减分 |
| 东北 | 艮 8 | 土 | 退气（八运 2004-2023） | 小幅加分 |

**用神 + 九运叠加示例**：

- 喜火命主 + 南方 → 双重加分（最优解）
- 喜金命主 + 西方 → 用神是金但九运衰金 → "个人加分 + 时代不加分"，可用但效果递减
- 忌火命主 + 南方 → 是忌神且时代当令 → 整体能量大但方向反，**应避免长期居所朝南**

## 四、应用场景的能量量级

按 [`zhuyun_overview.md`](./zhuyun_overview.md) §三的载体排序，方位助运在不同场景的强度：

| 等级 | 场景 | 重点判断 |
|---|---|---|
| ★★★★★ | **长期居所**：城市选择、住宅朝向、卧室位置、床头朝向 | 必须用神方位 / 至少不在忌神方位 + 九运衰方双负向 |
| ★★★★ | **长期办公位**：办公室坐向、座位面朝、显示屏朝向 | 主用神方位为坐向；至少避免忌神方位+九运衰方双负向 |
| ★★★ | **频繁出入**：大门朝向、客厅主朝向、灶位 | 主用神方位为佳；与居所大方位协调 |
| ★★ | **偶发短居**：长期出差住所、临时驻外、长假度假 | 主色用用神方位；可结合该年流年方位加成 |
| ★ | **短期出行**：旅行 / 短期商务、单次出差 | 影响最小；用神方位为加成不为约束 |

**判断顺序**：从★★★★★往下补。**不要花大力气挑度假地的方位，却让床头长年朝向忌神方位**——这是方位助运最常见的本末倒置。

## 五、用神方位 vs 九运旺方的协同与冲突

方位助运的复杂之处在于**两套权威坐标系**有时一致、有时冲突。统一处理矩阵：

| 命主方位 | 在用神方位 | 在忌神方位 |
|---|---|---|
| **在九运旺方** | **双吉**（最优）：用神 + 时代双加分 | **中性偏负**：能量大但方向反，长期居所应避免 |
| **在九运衰方** | **单吉**：用神加分但时代衰，能量递减 | **双忌**（最劣）：用神 + 时代双减分，长期居所应避免 |

### 5.1 协同情况

- 喜火命主 + 南方 = 双吉
- 喜土命主 + 西南 / 东北 = 双吉（坤艮土在九运里有未来生气 / 退气加分）
- 喜水命主 + 北方 = 单吉（用神但当下九运不加成）

### 5.2 冲突情况的处理

- **情况 A**：命主用神方位 = 九运衰方
  - 例：喜金命主，西方是用神，但 2024-2043 九运里西方衰
  - 处理：仍以用神方位为主选；九运衰方的"减分"通过其他维度（如颜色 / 时辰）补偿
  - 心智锚：**个人时空 > 时代时空**

- **情况 B**：命主忌神方位 = 九运旺方
  - 例：忌火命主，南方是忌神，但 2024-2043 九运里南方当令
  - 处理：长期居所避免朝南；如不可避免（已购房等），通过家居布置（避免大量火属性物品 / 加水属性平衡）减损
  - 心智锚：**南方时代能量大，但能量方向与你的需求相反，类似顶风行船**

- **情况 C**：用神方位与忌神方位都被九运改变了相对关系
  - 例：原本"中性"的东方，因为九运里"木生火"加分，变得对喜火命主有利
  - 处理：扩大候选方位池，把"次要选择"提升为"备选"

## 六、各应用场景的具体决策

### 6.1 居所朝向

**坐向定义**：房屋"坐"是背靠的方向，"向"是面对的方向。本仓库讨论"坐向"时统一指**正向**（即"坐 X 向 Y"中的 Y）。

**判断原则**：
- 大门朝向 = 主能量进入方向 → 应用神方位
- 主卧朝向 = 长期能量栖居方向 → 应用神方位
- 客厅主向 = 日常活动方向 → 协调用神方位

**实操**：
- 喜火命主：优先选朝南户型；其次东 / 东南（生火）
- 喜水命主：优先选朝北户型
- 喜木命主：优先选朝东 / 东南户型
- 喜金命主：优先选朝西 / 西北户型
- 喜土命主：优先选朝西南 / 东北户型；中央位置户型加分

> **现实约束**：城市内可选户型有限。"朝向 + 用神匹配 + 价格 + 通勤"四项约束下，朝向往往不是首要权重。处理：朝向不达标时，**通过家居布置**（颜色、家具方向、灶位）部分补偿。

### 6.2 床头朝向

**床头 = 人体长达 8 小时面对的方向**。其能量量级仅次于居所朝向，是方位助运中第二重要的载体。

**判断原则**：床头朝向 = 用神方位为佳；避免忌神方位。

**实操速记**：
- 喜火 → 床头朝南
- 喜水 → 床头朝北
- 喜木 → 床头朝东 / 东南
- 喜金 → 床头朝西 / 西北
- 喜土 → 床头朝西南 / 东北

**与卧室门位置的关系**：床头不直对门（传统风水"穿心煞"），即使方位对也要避开门正对。

### 6.3 办公座位

- **坐向**：背靠 = 用神方位的对侧（即"坐 = 对侧、向 = 用神方位"）
- **面朝**：日常视线方向 = 用神方位
- **显示屏 / 工作面**：与面朝方位协调

**实操**：
- 喜火命主：座位坐北朝南（背北，面南）
- 喜水命主：座位坐南朝北
- 喜木命主：座位坐西朝东
- 喜金命主：座位坐东朝西

### 6.4 大门 / 灶位

- **大门朝向**：参照 §6.1 居所朝向，能量量级稍弱于卧室
- **灶位**：传统风水重要节点，灶口朝向与火气有关；命主忌火时灶口避免朝南；命主喜火时灶口朝南 / 朝东

> **范围说明**：本仓库不展开玄空飞星 / 八宅游年的细节；如需更精细的家居布置，建议结合专业风水师建议，本文方位框架是"宏观方向"层面的判断。

### 6.5 长期出差 / 异地工作

- 短期（< 3 个月）：方位影响有限，按个人偏好即可
- 中期（3-12 个月）：开始累积影响，按用神方位选驻地朝向
- 长期（> 12 个月）：等同长期居所，按 §6.1 处理

### 6.6 城市层级的发展地点选择

宏观方位的城市选择，与 [`prompts/full_analysis.md`](../prompts/full_analysis.md) Step 6「发展地点」直接挂钩。

**国内方位粗分**（以中原为参考点）：
- **南**：广州 / 深圳 / 海口 / 福州 / 厦门 → 火属性城市
- **北**：北京 / 哈尔滨 / 长春 → 水属性城市
- **东**：上海 / 南京 / 杭州 → 木属性城市
- **东南**：宁波 / 温州 / 福州 → 木属性城市（含火气）
- **西**：成都 / 重庆 / 兰州 → 金属性城市
- **西北**：西安 / 银川 / 兰州 → 金属性城市
- **西南**：昆明 / 贵阳 / 南宁 → 土属性城市
- **东北**：沈阳 / 大连 / 长春 → 土属性城市（含金气）

**判断纪律**：
- 先按用神方位筛城市梯队
- 再叠加九运（2024-2043 南方城市加分）
- 最后结合现实因素（行业聚集、通勤、家庭、签证），方位是**1 个权重之一**而非唯一决定因素

**国际方向**：
- 美洲 = 大体属金（西方 + 西北）
- 欧洲 = 大体属金（含一定火气）
- 东南亚 = 火 / 木混合
- 日韩 = 东方属木
- 澳洲 = 南方属火

> 国际方向的五行属性争议较多，本表仅作宏观参考；具体国家 / 城市需结合实际地理位置精确判断。

## 七、九运 20 年内的方位趋势

**2024-2043 九紫离火运**期间，方位旺衰会**保持稳定**（不像流年那样每年变）。具体趋势：

- **南方城市 / 南向居所**：长期得令，是该 20 年里能量最强的方位选择
- **北方城市 / 北向居所**：未来生气（迎接下一运），适合长期布局
- **东方 / 东南方**：木生火，加分；适合喜火 / 喜木命主
- **西方 / 西北方**：衰气 / 死气；不利长期居所，但喜金命主仍可用（个人时空 > 时代时空）
- **东北方**：上一运（八运 2004-2023）当令，余气尚存；适合喜土命主
- **西南方**：未来一运（2044-2063 一运后接二运）方向，长期布局价值

> **20 年内不会变**：以上方位旺衰判断在 2024-2043 全段稳定，仅在 2043-2044 进入下一运时切换。

## 八、决策流程示例

**示例命主**：丙火日主，生于酉月（财格当令），命局火弱金重，木印缺位。
**用神判定**：用神木火，忌神金水。
**当下时间**：2026 年（九紫离火运第 3 年）。

### Step 1 · 用神 → 推荐 / 避免方位

| 类别 | 五行 | 方位 |
|---|---|---|
| 用神主方位 | 木火 | 东 / 东南 / 南 |
| 喜神辅方位 | 木→火链中段 | 同上 |
| 忌神方位 | 金水 | 西 / 西北 / 北 |
| 中性 | 土 | 西南 / 东北 / 中 |

### Step 2 · 九运加权

- 南方（火当令）→ ★★★★★（双加分）
- 东方 / 东南方（木生火）→ ★★★★（用神 + 加分）
- 北方（水未来生气，但与命主忌神冲突）→ ★（用神是忌但时代未来生气，相互抵消偏负）
- 西方 / 西北方（金衰气）→ ★（双减分）
- 西南方（土未来生气，与命主中性）→ ★★★（中性 + 时代加分）

### Step 3 · 落到载体

- ★★★★★ 长期居所：优先选朝南户型；床头朝南
- ★★★★ 办公座位：坐北朝南；显示屏朝南
- ★★★★ 备选：朝东 / 东南户型；床头朝东
- ★★ 长期出差：优先南方城市（深圳 / 厦门）+ 东南方城市（杭州 / 上海）
- ✕ 避免：长期住西向户型 / 床头朝西 / 在西北部城市长居

### Step 4 · 城市梯队推荐

| 梯队 | 城市 | 评级理由 |
|---|---|---|
| 第一梯队 | 深圳、广州、厦门、海口、福州 | 南方 + 九运当令 |
| 第二梯队 | 杭州、上海、南京、宁波 | 东 / 东南 + 木生火 |
| 第三梯队 | 北京（强经济权重，但方位减分）、武汉、长沙 | 行业资源补偿方位 |
| 不推荐 | 沈阳、大连、西安、兰州、乌鲁木齐 | 西 / 西北 / 东北方位减分 |

### Step 5 · 禁忌清单

- ❌ 长期居住朝西 / 西北的户型
- ❌ 床头朝北或西
- ❌ 办公座位面朝西 / 西北
- ❌ 移居西部 / 西北部城市作为长期发展地

## 九、常见误区辨析

### 9.1 误区一："南方都是好的"

**纠正**：南方对**喜火命主**是用神 + 九运双加分；对**忌火命主**是忌神方位（即使九运当令，方向相反）。"南方旺"是九运背景，不是个人最优。

### 9.2 误区二："北京 = 北方 = 水方位"

**纠正**：方位判断是相对的。北京从全国地理看属北方（水），但具体建筑朝向、办公位等微观方位仍要独立判断。**地理方位 vs 建筑朝向**是两层判断。

### 9.3 误区三："门朝东就好"

**纠正**：东方属木。对喜木 / 喜火命主有利；对忌木命主（如喜金命主）反而不利。**没有"对所有人都好的方位"**。

### 9.4 误区四："九紫离火 = 所有人都该去南方"

**纠正**：九运是时代背景；命主用神才是个人方向。忌火命主即使在九运里也应避免长期居住南方城市。九运的意义是"时代加权"，不是"逆个人需求"。

### 9.5 误区五："看罗盘就能知道方位旺衰"

**纠正**：罗盘是工具（用于精确测向），它本身不告诉你"对你这个命主是吉是凶"。罗盘 + 用神 + 九运 = 完整判断。**单看罗盘的"二十四山吉凶表"是脱离命主的伪精准**。

## 十、流派分歧的处理

- **方位坐标系**：本方法论以**后天八卦九宫**为坐标系（坎北 / 离南 / 震东 / 兑西 …）。先天八卦坐标系（乾南 / 坤北）仅在"先天 vs 后天"理论辨析时提及，不进入助运实操。
- **二十四山 vs 八卦九宫**：本方法论用八卦九宫粗分（八方 + 中宫）；二十四山（如壬子癸 / 丑艮寅）的精细划分留给专业风水实操，本文不展开。
- **玄空飞星 / 八宅游年 / 三合派**：流派各异，本文不强行统一；居所内部细节布置建议结合专业风水师建议，本文方位框架属于"宏观方向"层面。
- **当代衍生体系（"幸运方位 App"、"塔罗方位卡"、"星座方位"等）**：不进入主流程。

> 仲裁规则与 [`zhuyun_overview.md`](./zhuyun_overview.md) §五一致。
