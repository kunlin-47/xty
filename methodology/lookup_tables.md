# 八字硬数据查表（lookup_tables）

> 本文档收录八字命理中**结构化、可枚举、有确定答案**的硬数据，供 AI 解盘时直接对表查询。
>
> **流派说明**：本表收录子平派主流通用数据。藏干本/中/余气次序、长生十二宫（火土同根）、地支六合化气等，凡传统流派少数分歧处，采用《子平真诠》《滴天髓》主线。如发现具体规则与你常用流派不同，请提 issue 讨论。
>
> **不收录**：
> - 排盘公式（年上起月、日上起时、起运天数）—— 由专业排盘软件负责，AI 不需要算
> - 概念解释和推理逻辑 —— 见 `basics.md`
> - 三元九运 —— 见 `sanyuan_jiuyun.md`
> - 神煞（天乙贵人、文昌、华盖、驿马等）—— 流派分歧大、用法多变，暂不收录

## 二、十二地支与藏干

藏干分为**本气、中气、余气**三层。本气最强，是地支的"主气"；中气次之，常与方位/季节相关；余气最弱，多为前一支的延续。

判通根强弱时：本气根 > 中气根 > 余气根。

| 地支 | 阴阳 | 五行 | 时辰 | 本气 | 中气 | 余气 |
|---|---|---|---|---|---|---|
| 子 | 阳 | 水 | 23-01 | 癸 | — | — |
| 丑 | 阴 | 土 | 01-03 | 己 | 癸 | 辛 |
| 寅 | 阳 | 木 | 03-05 | 甲 | 丙 | 戊 |
| 卯 | 阴 | 木 | 05-07 | 乙 | — | — |
| 辰 | 阳 | 土 | 07-09 | 戊 | 乙 | 癸 |
| 巳 | 阴 | 火 | 09-11 | 丙 | 庚 | 戊 |
| 午 | 阳 | 火 | 11-13 | 丁 | 己 | — |
| 未 | 阴 | 土 | 13-15 | 己 | 丁 | 乙 |
| 申 | 阳 | 金 | 15-17 | 庚 | 壬 | 戊 |

**记忆要点**：
- 四正（子午卯酉）藏单干，本气即唯一主气
- 四生（寅申巳亥）藏三干：本气、中气（长生关系）、余气
- 四库（辰戌丑未）藏三干：本气（土）、中气（库藏的木火金水）、余气
- 午、亥仅藏两干

## 五、十神推导矩阵

以日主为中心，与"对方"的关系决定十神类型。同性 vs 异性进一步分偏 vs 正。

| 关系 | 阴阳同性 | 阴阳异性 |
|---|---|---|
| 生我 | **偏印**（枭） | **正印** |
| 同我 | **比肩** | **劫财** |
| 我生 | **食神** | **伤官** |
| 我克 | **偏财** | **正财** |
| 克我 | **七杀**（偏官） | **正官** |

**使用方法**（以日主丙火为例）：

1. 先看对方的五行：
   - 对方是木 → 生我（印）
   - 对方是火 → 同我（比劫）
   - 对方是土 → 我生（食伤）
   - 对方是金 → 我克（财）
   - 对方是水 → 克我（官杀）
2. 再看阴阳：
   - 丙（阳）遇甲（阳）→ 同性 → 偏印
   - 丙（阳）遇乙（阴）→ 异性 → 正印
   - 以此类推

## 六、地支六合

两两相合，化气如下表。

| 组合 | 化气 |
|---|---|
| 子 + 丑 | 土 |
| 寅 + 亥 | 木 |
| 卯 + 戌 | 火 |
| 辰 + 酉 | 金 |
| 巳 + 申 | 水 |
| 午 + 未 | 土（一说"日月合"，化气有争议） |

**力量**：六合力量中等，弱于三合，强于半合。

## 七、地支三合 / 半合

### 7.1 三合局

三个地支合化为一个五行局。三合的核心是"中字"（午、酉、子、卯之一）。

| 三字 | 化气局 |
|---|---|
| 寅 + 午 + 戌 | 火局 |
| 巳 + 酉 + 丑 | 金局 |
| 申 + 子 + 辰 | 水局 |
| 亥 + 卯 + 未 | 木局 |

### 7.2 半合规则

**含中字**的两字组合算半合，力量约为三合的一半：

| 半合（前半） | 化气 | 半合（后半） | 化气 |
|---|---|---|---|
| 寅 + 午 | 火 | 午 + 戌 | 火 |
| 巳 + 酉 | 金 | 酉 + 丑 | 金 |
| 申 + 子 | 水 | 子 + 辰 | 水 |
| 亥 + 卯 | 木 | 卯 + 未 | 木 |

**不含中字**的两字（如寅戌、巳丑、申辰、亥未）通常**不算半合**，可视为弱关联。

## 八、地支六冲

对宫相冲，相距 180 度，能量直接对抗。

| 冲对 | 五行属性 |
|---|---|
| 子 — 午 | 水冲火 |
| 丑 — 未 | 土土相冲（库冲） |
| 寅 — 申 | 木冲金 |
| 卯 — 酉 | 木金相冲 |
| 辰 — 戌 | 土土相冲（库冲） |
| 巳 — 亥 | 火冲水 |

**特点**：六冲是术数中变动信号最强的互动，常对应居住地、关系、工作、健康的实质性变化。

## 十二、空亡（旬空）

六十甲子分为六旬，每旬十天干配十地支，剩余两支即"空亡"（旬中无对应天干）。

| 旬首 | 旬末 | 空亡两支 |
|---|---|---|
| 甲子 | 癸酉 | 戌、亥 |
| 甲戌 | 癸未 | 申、酉 |
| 甲申 | 癸巳 | 午、未 |
| 甲午 | 癸卯 | 辰、巳 |
| 甲辰 | 癸丑 | 寅、卯 |
| 甲寅 | 癸亥 | 子、丑 |

**使用方法**：根据日柱所在的旬，查出该命主的空亡两支。如日柱是丙寅（在甲子旬），则空亡为戌、亥。

**特点**：空亡的支位"力量减半"或"实事虚化"，但遇冲、合可解空亡。
