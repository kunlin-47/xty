# 八字硬数据查表（lookup_tables）

> 本文档收录八字命理中**结构化、可枚举、有确定答案**的硬数据，供 AI 解盘时直接对表查询。
>
> **流派说明**：本表收录子平派主流通用数据。藏干本/中/余气次序、长生十二宫（火土同根）、地支六合化气等，凡传统流派少数分歧处，采用《子平真诠》《滴天髓》主线。如发现具体规则与你常用流派不同，请提 issue 讨论。
>
> **不收录**：
> - 排盘公式（年上起月、日上起时、起运天数）—— 由专业排盘软件负责，AI 不需要算
> - 概念解释和推理逻辑 —— 见 `basics.md`
> - 三元九运 —— 见 `sanyuan_jiuyun.md`
> - 大部分神煞（文昌、华盖、驿马、桃花等）—— 流派分歧大、用法多变，暂不收录
>
> **例外**：助运专题需要的少数神煞会在本表收录（如 §十六 天乙贵人速查表，被 [`zhuyun_guiren.md`](./zhuyun_guiren.md) 调用）。神煞收录的标准：流派分歧已收敛、有明确助运应用、规则可枚举。

## 二、十二地支与藏干

藏干分为**本气、中气、余气**三层。本气最强，是地支的"主气"；中气次之，常与方位/季节相关；余气最弱，多为前一支的延续。

判通根强弱时：本气根 > 中气根 > 余气根。

**记忆要点**：
- 四正（子午卯酉）藏单干，本气即唯一主气
- 四生（寅申巳亥）藏三干：本气、中气（长生关系）、余气

## 五、十神推导矩阵

以日主为中心，与"对方"的关系决定十神类型。同性 vs 异性进一步分偏 vs 正。

| 关系 | 阴阳同性 | 阴阳异性 |
|---|---|---|
| 生我 | **偏印**（枭） | **正印** |
| 同我 | **比肩** | **劫财** |
| 我生 | **食神** | **伤官** |
| 我克 | **偏财** | **正财** |
| 克我 | **七杀**（偏官） | **正官** |

**使用方法**（以日主丙火为例）：

1. 先看对方的五行：
   - 对方是木 → 生我（印）
   - 对方是火 → 同我（比劫）
   - 对方是土 → 我生（食伤）
   - 对方是金 → 我克（财）
   - 对方是水 → 克我（官杀）
2. 再看阴阳：
   - 丙（阳）遇甲（阳）→ 同性 → 偏印
   - 丙（阳）遇乙（阴）→ 异性 → 正印
   - 以此类推

## 六、地支六合

两两相合，化气如下表。

| 组合 | 化气 |
|---|---|
| 子 + 丑 | 土 |
| 寅 + 亥 | 木 |
| 卯 + 戌 | 火 |
| 辰 + 酉 | 金 |
| 巳 + 申 | 水 |
| 午 + 未 | 土（一说"日月合"，化气有争议） |

**力量**：六合力量中等，弱于三合，强于半合。

## 七、地支三合 / 半合

### 7.1 三合局

三个地支合化为一个五行局。三合的核心是"中字"（午、酉、子、卯之一）。

| 三字 | 化气局 |
|---|---|
| 寅 + 午 + 戌 | 火局 |
| 巳 + 酉 + 丑 | 金局 |
| 申 + 子 + 辰 | 水局 |
| 亥 + 卯 + 未 | 木局 |

### 7.2 半合规则

**含中字**的两字组合算半合，力量约为三合的一半：

| 半合（前半） | 化气 | 半合（后半） | 化气 |
|---|---|---|---|
| 寅 + 午 | 火 | 午 + 戌 | 火 |
| 巳 + 酉 | 金 | 酉 + 丑 | 金 |
| 申 + 子 | 水 | 子 + 辰 | 水 |
| 亥 + 卯 | 木 | 卯 + 未 | 木 |

**不含中字**的两字（如寅戌、巳丑、申辰、亥未）通常**不算半合**，可视为弱关联。

## 十二、空亡（旬空）

六十甲子分为六旬，每旬十天干配十地支，剩余两支即"空亡"（旬中无对应天干）。

| 旬首 | 旬末 | 空亡两支 |
|---|---|---|
| 甲子 | 癸酉 | 戌、亥 |
| 甲戌 | 癸未 | 申、酉 |
| 甲申 | 癸巳 | 午、未 |
| 甲午 | 癸卯 | 辰、巳 |
| 甲辰 | 癸丑 | 寅、卯 |
| 甲寅 | 癸亥 | 子、丑 |

**使用方法**：根据日柱所在的旬，查出该命主的空亡两支。如日柱是丙寅（在甲子旬），则空亡为戌、亥。

**特点**：空亡的支位"力量减半"或"实事虚化"，但遇冲、合可解空亡。

## 十三、五行 ↔ 颜色映射

每个五行对应一个**主色族**（含主色、辅色、典型代表色）。色相归属以**主流色感**为准；同一颜色因深浅、饱和度可能有细微浮动，本表给出大类划分。

| 五行 | 主色 | 辅色（同族色感） | 典型代表 | 备注 |
|---|---|---|---|---|
| **木** | 青、绿 | 翠绿、墨绿、嫩绿、原木色、抹茶绿 | 树叶、草地、原木家具 | 阴木（乙）偏柔绿；阳木（甲）偏深翠 |
| **火** | 红、橙、紫 | 玫红、酒红、橘色、紫色、粉色（弱火） | 红灯、夕阳、玫瑰 | 粉色 = 红的稀释，仍属火但能量弱 |
| **土** | 黄、棕 | 米黄、卡其、咖啡、土黄、焦糖、大地色 | 沙土、陶器、麦田 | 深咖近黑时向水靠拢 |
| **金** | 白、银、金 | 灰白、香槟、银灰、亮金 | 金属、月光、白瓷 | 银偏阴金（辛），金偏阳金（庚） |
| **水** | 黑、蓝、灰 | 深蓝、藏青、深灰、墨黑 | 水面、夜空、墨色 | 深蓝 / 藏青常被误归绿系，需注意 |

### 13.1 主色判定规则

- **饱和色**（鲜艳的纯色）：直接按色相归属
- **混合色**（多种色相调和）：按主导色相归属
- **明度变化**（深 / 浅）：色相不变，五行不变，但能量强度变（深 → 强，浅 → 弱）
- **金属质感（带光泽）**：归金；同色相但哑光归原五行（如哑光黄 = 土，金黄带光泽 = 金）

### 13.2 五行 → 颜色生克对照（用于配色判断）

| 主色五行 | 相生辅色（推荐） | 相克辅色（慎用 / 例外可用） |
|---|---|---|
| 木 | 火（红橙紫，木生火） | 金（白银金，金克木） |
| 火 | 土（黄棕，火生土） | 水（黑蓝灰，水克火） |
| 土 | 金（白银金，土生金） | 木（青绿，木克土） |
| 金 | 水（黑蓝灰，金生水） | 火（红橙紫，火克金） |
| 水 | 木（青绿，水生木） | 土（黄棕，土克水） |

### 13.3 中性 / 灰区色处理

| 颜色 | 五行归属 | 备注 |
|---|---|---|
| 米色 / 浅咖 | 土（弱） | 弱化的土色 |
| 浅灰 | 金（弱）| 偏金多于水 |
| 深灰 | 水（弱） | 偏水多于金 |
| 雾霾蓝 / 灰蓝 | 水（弱） | 蓝色稀释 |
| 浅粉 | 火（弱） | 红色稀释 |
| 米白 / 暖白 | 金（弱） | 白色降低饱和 |
