# 颜色助运（yanse_zhuyun）

> **文档定位**：助运维度专题。本文是 [`zhuyun_overview.md`](./zhuyun_overview.md) 三层叠加框架在**颜色维度**的具体应用。
>
> 凡需要为具体命主选色（穿戴 / 家居 / 车 / 品牌视觉 / 关键场合穿搭）时，按本文流程套用即可。

## 一、颜色助运的核心机制

颜色对人的能量影响主要通过两条通路：

1. **视觉持续暴露**：颜色波长对应不同光频，长期视觉接触会影响情绪、专注力与生理节律
2. **五行能量类比**：传统命理将色系与五行对应，命主用神所属五行的色系可视为"该五行能量的可视化补给"

第二条是助运体系的工作机制。第一条提供了部分现代生理学解释，但不取代命理判断。

> **铁律**：**先有用神判定，再选色**。脱离命主谈"招财色 / 桃花色 / 升职色"是商业话术，不属于本方法论。

## 二、五行 ↔ 色系映射

详细的色系对应表（含主色 / 辅色 / 色温倾向）见 [`lookup_tables.md`](./lookup_tables.md) §十三。本文只做应用层面的速记：

| 五行 | 主色 | 辅色 | 典型场景代表 |
|---|---|---|---|
| 木 | 青、绿 | 翠绿、墨绿、嫩绿、原木色 | 树叶、草地、原木家具 |
| 火 | 红、橙、紫 | 玫红、酒红、橘色、紫色 | 红灯、夕阳、玫瑰 |
| 土 | 黄、棕 | 米黄、卡其、咖啡、土黄 | 沙土、陶器、麦田 |
| 金 | 白、银、金 | 灰白、香槟、银灰、亮金 | 金属、月光、白瓷 |
| 水 | 黑、蓝、灰 | 深蓝、藏青、深灰、墨黑 | 水面、夜空、墨色 |

> **辨析点**：
> - **粉色** = 红的稀释 → 仍属火，但能量弱化
> - **深蓝 / 藏青** = 水（不是木，常被误归绿系）
> - **大地色 / 焦糖色** = 土
> - **银 vs 金** = 都属金，但银偏阴金、金偏阳金；命局喜阳金（如阴日主忌阴金）时优先选金不选银

## 三、三层框架在颜色维度的应用

### 3.1 第一层 · 命主用神

输入命主的用神 / 喜神 / 忌神五行。

例 1：日主丙火，月令酉金（财格当令），命局火弱金重 → 用神：木火，忌神：金水。
例 2：日主壬水，月令子水，命局水旺无制 → 用神：土火，忌神：金水。

### 3.2 第二层 · 五行 → 色系映射

按 §二查表，得出推荐色系与避免色系。

例 1（喜木火）：推荐 青 / 绿 / 红 / 橙 / 紫；避免 白 / 银 / 黑 / 蓝 / 灰。
例 2（喜土火）：推荐 黄 / 棕 / 红 / 橙；避免 白 / 银 / 黑 / 蓝 / 灰；中性 青 / 绿（木生火可参考）。

### 3.3 第三层 · 时空加权（当下九运）

2024-2043 九紫离火运，火当令；木生火，木有助旺加分；金水退气 / 衰气，能量弱。

| 五行 | 当下九运时态 | 颜色加分 / 减分 |
|---|---|---|
| 火 | **当令** | 红 / 橙 / 紫系 **大幅加分** |
| 木 | 死气但生火 | 青 / 绿系 **加分**（生火） |
| 土 | 退气（八运 2004-2023 余气） | 黄 / 棕系 **小幅加分** |
| 金 | 衰气（七运 1984-2003） | 白 / 银 / 金系 **不加不减或微减** |
| 水 | 远离当令 | 黑 / 蓝 / 灰系 **减分** |

**用神 + 九运叠加示例**：

- 喜火命主 + 九运当令 → 红橙紫系**双重加分**（最优解）
- 喜水命主 + 九运衰水 → 黑蓝系是用神但不得令 → "个人加分 + 时代不加分"，可用但配比要节制
- 忌火命主 + 九运当令火 → 红橙紫系是忌神且时代当令 → 整体能量大但方向反，**应避免主色**

## 四、应用场景的能量量级

按 [`zhuyun_overview.md`](./zhuyun_overview.md) §三的载体排序，颜色助运在不同场景的强度：

| 等级 | 场景 | 重点判断 |
|---|---|---|
| ★★★★★ | **贴身长期**：内衣、内搭、贴身首饰、床品、枕头、手机壳 | 必须用用神色 / 至少不用忌神色 |
| ★★★★ | **居所大件**：主墙、沙发、床架、主灯、主窗帘 | 主用神色为底；用神过盛时改用辅助色避免堆叠 |
| ★★★ | **日常移动**：外套、包、鞋、钱包、车、办公背景 | 主色用用神色或中性色；点缀可加辅色 |
| ★★ | **偶发场合**：面试 / 签约 / 重要洽谈穿搭 | 主色用用神色；可结合该日流年色加成 |
| ★ | **装饰偶遇**：装饰画、短期摆件、礼物 | 影响最小，可不严格按用神，但不应是大面积忌神色 |

**判断顺序**：从★★★★★往下补。**不要花大力气挑一幅装饰画，却让床品和内衣长期是忌神色**——这是颜色助运最常见的本末倒置。

## 五、配色判断（单色 vs 主辅搭配）

实际生活中很少全身只穿一种颜色，大部分场景是**主色 + 辅色 + 点缀**的搭配。判断原则：

### 5.1 主辅色搭配

- **主色**（占比 60-70%）：用神 / 喜神色，决定整体方向
- **辅色**（占比 20-30%）：与主色相生的五行色（如主色火 → 辅色木），强化主色能量
- **点缀**（占比 5-10%）：可用中性色，避免大面积忌神色

### 5.2 相生 vs 相克的搭配规则

- **相生搭配**（推荐）：木+火、火+土、土+金、金+水、水+木
  - 例：主色绿 + 辅色红 → 木生火，能量协同
- **相克搭配**（慎用）：木+金、金+火、火+水、水+土、土+木
  - 例：主色绿 + 辅色白 → 金克木，能量打架
  - **例外**：命主忌木需要金克制时，木+金搭配反而合适（用克制方向破忌神）

### 5.3 中性色（黑白灰 + 米咖）的角色

- **黑 / 深灰** = 水属性，对喜水命主是用神，对忌水命主是忌神
- **白 / 浅灰** = 金属性，同理
- **米色 / 咖色** = 土属性
- **真正的"中性"**：实际上不存在；任何颜色都有五行归属。"中性"只是相对意义上的低饱和、低能量

### 5.4 配色禁忌速记

| 命主用神 | 禁忌主色 | 慎用大面积 |
|---|---|---|
| 喜火 | 大面积黑 / 蓝（水克火） | 大面积白 / 金（火克金，泄火耗用神） |
| 喜水 | 大面积红 / 紫（火克水，但方向是水克火所以是火被压） | 大面积黄 / 棕（土克水） |
| 喜木 | 大面积白 / 银（金克木） | 大面积红 / 橙（木生火，泄木） |
| 喜金 | 大面积红 / 紫（火克金） | 大面积黑 / 蓝（金生水，泄金） |
| 喜土 | 大面积绿 / 青（木克土） | 大面积白 / 银（土生金，泄土） |

## 六、命局矛盾时的色系取舍

不是所有"喜火"命主都该堆红色。三种典型矛盾命局：

### 6.1 喜火 + 火极弱（命局缺火 / 火无根）

- 大胆补火 → 红 / 橙 / 紫系作主色
- 配合木 → 青 / 绿作辅色（木生火）
- 避免水（黑 / 蓝）

### 6.2 喜火 + 火过盛（命局火多但还需调候 / 流通用神）

- **不要堆红色** —— 火已过旺，再加只会失衡
- 改用木（青 / 绿）作主色 → 引导火气流通
- 或用土（黄 / 棕）作主色 → 火生土，泄火气

### 6.3 喜调候（如冬日喜火 / 夏日喜水）但忌神同向

- 冬日命主喜火调候，但火过旺会克金（如金为命局重要十神）→ 火与金的取舍要看哪个更急
- 通常**调候用神优先**，忌神色降为辅色或点缀

> **判断纪律**：色系建议必须基于具体命局结构，不能停留在"喜火 → 选红色"的一步映射。

## 七、当下九运（2024-2043）的色系加权

九紫离火运 20 年里，色系的"时代加权"如下：

| 色系 | 五行 | 时态 | 综合建议 |
|---|---|---|---|
| 红 / 橙 / 紫 | 火 | **当令** | 用神 + 时代双加分（除忌火命主外，普遍偏推荐） |
| 玫红 / 粉 | 火（弱） | 当令但能量弱 | 适合喜火但火不能过强的命主 |
| 青 / 绿 / 原木 | 木 | 死气但生火 | 木生火加分；适合喜木火命主 |
| 黄 / 棕 / 卡其 | 土 | 退气 | 余气尚存；适合喜土命主，喜火命主可作辅色 |
| 白 / 银 / 浅灰 | 金 | 衰气 | 时代不加分；喜金命主可用，但避免大面积 |
| 黑 / 蓝 / 藏青 | 水 | 远离当令 | 时代减分；喜水命主可用但配比节制 |

**九运 20 年内的色系趋势**（社会层面）：街道、品牌视觉、流行配色会向暖色系（红橙紫黄）倾斜，冷色系（黑蓝白银）热度递减 —— 这与"九紫离火"的能量趋势一致。

## 八、决策流程示例

**示例命主**：丙火日主，生于酉月（财格当令），命局火弱金重，木印缺位。
**用神判定**：用神木火，忌神金水。
**当下时间**：2026 年（九紫离火运第 3 年）。

### Step 1 · 用神 → 推荐 / 避免色系

| 类别 | 五行 | 颜色 |
|---|---|---|
| 用神主色 | 木火 | 青 / 绿 / 红 / 橙 / 紫 |
| 喜神辅色 | （木→火链中段） | 暖色调皆可 |
| 忌神色 | 金水 | 白 / 银 / 黑 / 蓝 / 灰 |

### Step 2 · 九运加权

- 红 / 橙 / 紫（火当令）→ ★★★★★（双加分）
- 青 / 绿（木生火）→ ★★★★（用神+加分）
- 白 / 银（金衰）→ ★（双减分）
- 黑 / 蓝（水远离当令）→ ★（双减分）

### Step 3 · 落到载体

- ★★★★★ 贴身：内衣 / 床品建议红系 / 紫系；可深红 / 玫红
- ★★★★ 居所大件：主沙发可深绿或墨红；主墙可暖白底+暖色画作
- ★★★ 日常：外套优先红 / 紫 / 绿；包可深绿或栗色
- ★★ 偶发：重要场合首选红 / 紫西装或饰品
- ★ 装饰：避免大面积白 / 银 / 黑配置

### Step 4 · 禁忌清单

- ❌ 大面积白 / 银 / 黑 / 蓝家居或穿戴
- ❌ 全身银白色金属感装扮
- ❌ 工作环境如长期处于冷色调，建议加暖色配饰平衡

### Step 5 · 命主可自由选择的灰区

- 黄 / 棕色：土，对此命主中性（土能泄火也能生金，看具体大运），可作辅色或日常使用
- 粉色：弱火，喜但能量弱，适合不想张扬补火的场合

## 九、常见误区辨析

### 9.1 误区一："喜火就全身红"

**纠正**：火过盛命主补火反而失衡；即使是火极弱命主，也不应纯色堆叠 —— 主辅色搭配（如绿+红）效果更好且不显刻意。

### 9.2 误区二："黑色显瘦显高级，对所有人都好"

**纠正**：黑 = 水。对喜水命主是用神，对忌水命主（尤其喜火喜土）是双重负向。"显高级"是审美判断，与命理能量是两回事。**忌水命主长期黑色穿搭，是颜色助运里最常见的错误**。

### 9.3 误区三："金色 = 招财"

**纠正**：金色属金，对**喜金命主**（如水弱金枯）是用神。但对**喜木命主**（金克木）反而是忌神。"招财"概念错位 —— 命理里的财星是命主所克的五行，不一定与"金色"对应。

### 9.4 误区四："九紫离火运 = 所有人都该穿红"

**纠正**：九运是**时代背景**，命主用神才是**个人方向**。忌火命主在九运里**仍应避免大面积红色**，只是因为时代能量加成，可以比上一运（八运土时代）少穿一点冷色。

### 9.5 误区五："彩虹能量 / 色彩疗愈"卡片决定每日穿色

**纠正**：现代衍生体系，不进入本方法论主流程。可作偶尔参考，但与命理用神冲突时以用神为准。

## 十、流派分歧的处理

- **色相 vs 色感 / 深浅取舍**：本方法论以"五行决定色系"为主线，色感个人化决定深浅 / 饱和度。即"喜火命主选红"是定的，"选鲜红还是深红"由命主自身偏好与场合决定。
- **粉色归属**：本方法论将粉色归火（红的弱化），不归"独立色系"。
- **金色 vs 黄色**：本方法论将金色归金（带光泽），黄色归土（哑光）；需依颜色质感判断而非色相绝对值。
- **大地色细分**：米黄 / 卡其 / 焦糖 / 咖啡均归土，但深咖近黑时会向水靠拢，需视具体情境。
- **当代衍生体系（彩虹能量、色彩心理学、色彩疗愈卡）**：不进入主流程，仅在不违背命主用神时可作辅助参考。
